## 설계 결정과 보존 정책

1. 신규 결과는 `version: 2`. 기존 전이 코드는 `compositePlayEngine.v1.ts`에 유지하며 저장된 v1 검증과 공통 전이 커널로 실제 사용한다. 미사용 코드가 아니므로 주석 처리하지 않는다.
2. v1 원본은 당시 파생값 검증 후 추가 규칙 검증을 수행한다. 정상 v1은 새 통계로 재작성하지 않고 그대로 반환한다. 모순이 있는 원본은 정규화에 실패하며 자동 합산에서 제외된다. 삭제하지 않는다.
3. v1 오류 자료에 대한 사용자용 재심 큐/차단 배너 연계는 별도 과제다. 단순 제외를 운영 승인으로 오인해서는 안 된다.
4. 만루 볼넷의 늦은 홈 도달은 원본 입력과 해결된 이동 행의 순서를 그대로 보존하고, 제3아웃 뒤 득점 권리만 정산한다. 현재 구현 범위는 타자·1루·2루 주자의 필수 진루 완료 후 추가 주루 태그 제3아웃이다. 그 외 어필/필수 베이스 미접촉 조합은 자동 확정 범위로 간주하지 않는다.
5. 동시 도루 묶음의 기본값은 1이다. 별도의 다음 시도는 다른 번호를 부여한다. 오버슬라이딩 아웃은 같은 묶음의 도루자로 기록한다. 시도 의도는 자동 추측하지 않는다.
6. 포일은 사건별 포수 포지션에 저장된다. 선수별 수비 포지션 이력과 누적 수비 표의 완전한 연계는 아직 없다.
7. 새 통계가 없는 v1에 IBB/TB/상대 AB를 0으로 확정하지 않는다. 자책점 역시 확정하지 않는다.
