# 안타 입력과 구조화 책임 실점 연결

기준일: 2026-09-08. 주루 매트릭스에 이어 기존 단타·2루타·3루타·홈런 액션을 동일 주루 검증 엔진으로 연결했다.

## 사용자 흐름

기존 안타 입력에서 주자 결과를 선택하면 `안타·주자 결과 검증` 패널이 표시된다. 베이스 충돌, 인정 득점, 타점, 추가 아웃, 공수 교대 여부를 확인하고 `검증 결과로 안타 기록`을 누른다.

- 후속 주자 아웃이 있으면 타자의 도달과 주자 결과 발생 순서, 아웃 종류를 입력해야 한다.
- 선행 주자 아웃에도 안타가 성립하고 선택한 루타수가 맞는지 확인하는 체크가 필요하다. 체크는 기록원 판단을 남기며 모든 KBO 안타 판정을 자동 판정하는 기능은 아니다.
- 포스 아웃이 포함된 타구는 안타 경로에서 반려하고 야수선택 판정을 확인하도록 안내한다.
- 제3아웃보다 늦은 타자 도달은 자동 확정하지 않고 추가 판정 대상으로 안내한다.
- 타점은 인정 득점 수를 기본으로 하되 기록원이 낮춰 입력할 수 있다. 인정 득점 수를 초과할 수 없다.
- 입력 중 경기 카운트·주자·점수·타순·타자·투수가 바뀌면 기존 입력을 적용하지 않는다.
- 아웃이 없는 안타의 순서는 기본 처리 순서이다. 실제 플레이의 세부 시각을 수집했다는 뜻은 아니다.

주자가 없는 안타와 홈런도 기존 버튼/API를 유지하면서 내부적으로 구조화 사건을 생성한다. API의 기존 두 인자는 유지하고 단타·2루타·3루타에 선택적인 세 번째 인자 `HitRunnerReview`를 추가했다.

## 데이터와 상태 전이

`PlayEvent.runnerPlay.input.batterHit`에 타자 ID, 안타 루타수, 도달 순서, 상대 투수 ID, 후속 아웃 시 안타 확인 여부를 저장한다. 기존 주자 이동은 같은 사건의 `movements`에 보관한다.

`applyHitWithAdvances`는 `resolveHitPlay`와 `resolveRunnerPlay`의 검증 결과를 사용한다. 임의로 주자를 밀어내는 이전 안타 전이를 대체했다.

- 베이스 충돌을 득점이나 추가 진루로 바꾸지 않는다.
- 새 타자의 책임 투수는 안타 당시 투수, 기존 주자는 원래 책임 투수를 유지한다.
- 득점·타점·아웃·라인스코어·타순·카운트·책임 투수를 한 액션으로 갱신한다.
- 홈런은 기존 주자와 타자의 득점을 각각 한 번만 계산한다. 타자 득점은 주자 문자열 목록에 중복 추가하지 않는다.
- 한 사건의 결과는 기존 상태 재생 모듈과 undo/redo 경로에 연결된다.
- 과거 CSV/집계가 읽을 수 있도록 진루 문자열에 `1루→2루`, `3루→홈 득점` 형태를 유지한다.

## 책임 실점 집계 연결

공통 `createStructuredRunnerIndex`를 기록원과 점수관의 선수 집계 경로에서 사용한다.

1. 이닝·초말·사건 ID로 원본 이벤트를 찾고 저장된 주루 입력을 검증한다.
2. 구조화된 사건이면 홈 도달 인정 여부, 출발/도착 루, 주자 식별자, 책임 투수를 문자열 추론보다 우선한다.
3. 같은 사건·주자의 중복 중계 행은 주루 처리에서 다시 적용하지 않는다.
4. 책임 투수가 명시적으로 미확인인 경우 현재 구원투수에게 임의로 실점을 부과하지 않는다.
5. 새 안타 타자의 책임 정보도 집계 중 주자 책임표에 유지한다.

이 연결은 기존 선수 집계 전체를 교체한 것이 아니다. 타석/투구/교체의 일부 처리는 문자중계를 계속 사용한다. 중복 중계 차단도 구조화된 주자 이동에 적용되며, 모든 타석 중복에 대한 전면 해결은 아니다.

자책점(`er`)은 기존 실책 문구 기반 추정 방식이 유지된다. 이번 단계에서 KBO 자책점 재구성, 책임 미확인 실점의 해소, 공식 자책점 보정을 완료했다고 해석하면 안 된다. 자책점 계산을 사건 원장 기반으로 분리하는 작업이 필요하다.

CSV의 `구조화 주루 기록`에 기존 주자뿐 아니라 안타 타자도 추가한다. 주자 없는 홈런도 타자·책임 투수·득점·타점의 한 행을 갖는다.

## 공식 규칙 참조

[KBO·KBSA 2025 공식야구규칙](https://6ptotvmi5753.edge.naverncp.com/KBO_FILE/ebook/pdf/2025_%EC%95%BC%EA%B5%AC%EA%B7%9C%EC%B9%99.pdf#page=156)의 9.04(타점), 9.05(안타), 9.06(단타·장타 결정)을 확인했다. 포스 아웃의 안타 불인정은 9.05(b)를 근거로 하며, 기타 선행 주자 아웃과 루타수 판단은 기록원의 확인을 요구한다. 제3아웃 득점 계산은 앞 단계에서 적용한 5.08 기준을 공유한다.

2026 판본 전체 대조와 모든 세부 판정의 자동화는 완료하지 않았다.
