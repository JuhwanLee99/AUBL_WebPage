## 남은 하네스 문제: gRPC 프록시 호환성

Firestore 에뮬레이터의 나머지 23건은 통과했다. 신규 차단 테스트 2건에서는 outbox가 재시도 필요 상태와 요청을 유지했지만 프록시가 관측한 요청 수가 0이어서 실패했다. 기대값을 약화하거나 이 결과를 실제 RPC 차단 성공으로 처리하지 않았다.
설치된 @firebase/firestore Node 구현이 @grpc/grpc-js와 GrpcConnection을 사용함을 확인했다. 이번에 작성한 HTTP/1 프록시는 그 전송을 처리하지 못한다. 실제 HTTP/2 gRPC 프록시로 교체하고 gRPC 오류/트레일러와 upstream 전달을 제어해야 한다. 신규 하네스 구현 오류로 보고하고 추가 수정 승인을 요청했으며, 승인 전에는 다시 수정하지 않았다.
목표 검증은 차단된 실제 RPC의 관측, 서버 revision/receipt 불변, 큐 유지, 연결 복구 뒤 같은 요청 ID로 단일 커밋이다. 이번 실패 지점 이후의 서버 불변/복구 검증은 완료되지 않았다.
