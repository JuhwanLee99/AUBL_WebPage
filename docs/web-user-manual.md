# 📘 AUBL 웹 플랫폼 사용 설명서

본 문서는 AUBL(Amateur University Baseball League) 웹 플랫폼을 이용하는 방문자(Guest), 일반 회원(Member), 관리자 및 기록원(Admin/Scorer)을 위한 기능별 가이드입니다.

## 공통 안내

- 브라우저 권장: 최신 Chrome, Safari, Edge
- 일부 관리 기능(기록원/관리자)은 데스크톱 또는 태블릿 가로 모드 환경을 권장합니다.
- 라우트 경로는 실제 배포 서비스 기준으로 작성되어 있습니다.

---

## 1. 👥 방문자 (Guest) 가이드

대상: 로그인을 하지 않은 일반 사용자  
권한: 공개 정보 열람, 일정/기록 조회, 문자중계/스코어보드 시청

### 1-1. 메인 및 리그 정보

AUBL의 주요 소식과 리그 소개를 확인하는 영역입니다.

- 랜딩 페이지 (`/`)
  - 상단 LIVE INFO(티커) 공지 확인
  - 주요 시즌 하이라이트/링크 확인
- 리그 소개 (`/intro`)
  - 리그 역사, 구조, 운영 정보 열람
- 회칙 (`/rules`)
  - 챕터/조항 단위 회칙 열람
- 참가팀 · 조편성 (`/intro/teams`)
  - 조별 참가팀 목록 확인
- 팀 허브 (`/teams`)
  - 팀 검색, 팀 상세 진입

### 1-2. 경기 일정 및 결과 확인

리그 전체 일정 흐름과 경기 상태를 확인합니다.

- 경기 일정 (`/schedule`)
  - 전체 일정 조회
  - 리스트/캘린더 기반 일정 탐색
- 라이브 일정 (`/schedule/live`)
  - 진행 중 경기만 모아보기
- 경기 결과 (`/schedule/results`)
  - 종료 경기 스코어/기록 요약 확인
- 조별 일정 (`/schedule/groups`)
  - 조(A~H) 기반 필터 조회
- 연습경기 (`/schedule/practice`)
  - 연습경기 전용 일정 조회

### 1-3. 순위 및 기록실

팀/선수 기록을 통합 조회하는 영역입니다.

- 기록 허브 (`/records`)
  - 개요(overview)
  - 팀 순위(standings)
  - 투수 기록(pitchers)
  - 타자 기록(batters)
  - 파워랭킹(power)
- 선수 상세 (`/records/player`, `/records/player/:playerId`)
  - 선수 단위 시즌/게임 로그 조회
  - 검색 및 필터 기반 탐색

### 1-4. 승부 예측 (`/prediction`) (베타 준비 중)

데이터 기반 승부 예측 기능의 프리뷰 영역입니다.

- 예측 실험실 구성 소개
- 향후 제공 예정 기능 안내
- 현재는 정식 예측 결과 제공 전 단계

### 1-5. 경기 중계 시청

실시간 경기 정보/중계 보조 화면을 시청합니다.

- 스코어보드 (`/scoreboard`, `/scoreboard/:matchId`)
  - 라이브 점수, 이닝, BSO, 라인스코어 확인
- 문자 중계 (`/scoreboard-text`, `/scoreboard-text/:matchId`)
  - 텍스트 기반 실시간 경기 상황 확인
- 라이브 오버레이 (`/live-overlay`, `/live-overlay/:matchId`)
  - 방송 송출용 오버레이 화면 확인

## 2. 👤 일반 회원 (Member) 가이드

대상: 회원가입 후 로그인한 사용자 (선수, 팀 관계자, 일반 회원)  
권한: 방문자 권한 전체 + 커뮤니티 상호작용 + 계정/알림 기능

### 2-1. 로그인 및 계정 관리

- 로그인/회원가입 (`/login`)
  - 이메일/소셜(구글) 로그인
- 계정 페이지 (`/account`)
  - 계정 기본 정보 확인
  - 역할/권한 확인
  - 로그아웃

### 2-2. 커뮤니티 이용

AUBL 공지, 외부 커뮤니티, 건의/문의 게시판을 이용합니다.

- 커뮤니티 메인 (`/community`)
  - 갤러리, 공지, 건의/문의 최근 글 한눈에 확인
- 갤러리 (`/community/gallery`)
  - 외부 갤러리 연동 영역
- 공지 목록 (`/community/notices`)
  - 카테고리(일반/경기공지/징계/긴급) 기반 확인
- 공지 상세 (`/community/notices/:noticeId`)
  - 상세 내용 열람
  - 댓글 사용(설정된 공지에 한함)
- 건의/문의 게시판 (`/community/inquiry`)
  - 플랫폼(앱/웹), 말머리(5종), 처리상태 필터 및 제목/작성자 검색
  - 말머리: 기능 개선 / 버그 신고 / 사용 문의 / 경기·기록 오류 / 기타
  - 비밀글은 목록에 표시되지만 작성자 및 관리자만 열람 가능
  - 로그인한 사용자 글쓰기 가능 / 본인·관리자 수정·삭제 가능
  - 댓글 작성(로그인 필요) 및 본인 댓글 삭제
- 건의/문의 작성 (`/community/inquiry/new`)
  - 플랫폼(앱/웹) 선택 — 웹에서 작성 시 웹이 기본 선택됨
  - 말머리(카테고리) 선택 후 제목/내용 작성
  - 비밀글 설정 가능

### 2-3. 팀 상세/팀 공지 열람

- 팀 상세 (`/teams/:teamId`)
  - 팀 소개/로스터/팀 공지 확인
- 팀 공지 상세 (`/teams/:teamId/notices/:noticeId`)
  - 팀 공지 상세 열람
  - 댓글/답글/좋아요 사용
  - 본인 댓글 삭제 (관리자/해당 팀 감독은 관리 권한으로 삭제 가능)

팀 공지사항 게시판 주요 사용 흐름

- 목록 화면(팀 상세 내 팀 공지)
  - 카테고리: 일반/훈련/경기/긴급
  - 고정 공지 우선 노출
  - 제목/내용/작성자 검색 및 결과 개수 확인
- 상세 화면(팀 공지 상세)
  - 공지 본문 + 카테고리/고정 상태 확인
  - 댓글/답글 작성, 좋아요, 실시간 반영
- 권한
  - 팀 공지/댓글은 팀 정책(권한)에 따라 열람 제한될 수 있음
  - 댓글 작성은 로그인 사용자 가능

### 2-4. 웹 알림 권한

- 첫 방문 시 브라우저 알림 권한 요청이 표시될 수 있습니다.
- 허용 시 주요 공지/이벤트 알림 수신이 가능합니다.
- 거부/보류 시 재요청은 일정 기간 후 다시 노출됩니다.

### 2-5. 감독(Coach) 팀 홈 관리 (3가지)

감독 권한 계정은 본인 팀 홈(`/teams/:teamId`)에서 아래 운영 기능을 사용할 수 있습니다.

1. 팀 브랜딩/소개 관리
   - 엠블럼(로고) URL 변경
   - 짧은 소개/상세 소개/연혁 수정

2. 팀 일정 운영 관리
   - 팀 홈에서 예정/진행 경기 및 최근 결과를 빠르게 확인
   - 전체 일정(`/schedule`)·결과(`/schedule/results`) 화면으로 이동해 팀 경기 일정을 운영 관점에서 관리

3. 선수 로스터 관리
   - 선수/스태프 등록 및 제거
   - 등번호, 포지션, 투/타, 프로필 이미지/소개 수정

팀 공지사항 게시판 관리(감독/관리자)

- 공지 작성: 제목/본문/카테고리 지정 후 등록
- 공지 고정/해제: 중요 공지 상단 유지
- 공지 삭제: 운영 정책에 맞는 공지 정리

## 3. 🛡️ 관리자 및 기록원 (Admin/Scorer) 가이드

대상: 리그 운영진 및 공식 기록원  
권한: 일반 회원 권한 전체 + 운영/기록 관리 기능

### 3-1. 관리자 패널 (`/admin`)

관리자 전용 콘텐츠 관리 메뉴입니다.

- 랜딩 관리 (`/admin/landing`)
  - LIVE INFO, 메인 히어로 문구, 스냅샷 카드 등 편집
- 리그 소개 관리 (`/admin/intro`)
  - 소개/히스토리/구조/포스트시즌 등 소개 콘텐츠 편집
- 회칙 관리 (`/admin/rules`)
  - 회칙 헤더/챕터 JSON 구조 편집
- 팀 소개 관리 (`/admin/teams`)
  - 참가팀/조편성 및 관련 문구 편집
- 권한 관리 (`/admin/roles`)
  - 감독 권한 부여/해제

### 3-2. 경기 일정 관리 (`/schedule/manage`)

- 경기 생성/수정/삭제(휴지통 이동)
- 경기 상태 전환: 예정/진행 중/종료/취소
- 으뜸/버금 구분 조정
- 연습경기 포함 일정 운영

### 3-3. 공지사항 및 건의/문의 관리

**공지사항**

- 공지 작성 (`/community/notices/new`) (관리자 전용)
- 공지 카테고리 지정: 일반/경기공지/징계/긴급
- 공지 등록 후 목록/상세 즉시 반영

**건의/문의 게시판 관리**

- 건의/문의 상세 (`/community/inquiry/:inquiryId`)에서 처리 상태 드롭다운으로 즉시 변경
  - 미처리(빨강) / 처리 중(노랑) / 처리 완료(초록)
- 비밀글 포함 모든 글 열람 가능
- 모든 글·댓글 수정 및 삭제 가능

### 3-4. 전자 기록지 작성 (`/scorekeeper`)

[중요] PC 또는 태블릿 가로 모드 권장

- 경기 선택 및 라인업 입력
- 플레이 기록 입력
  - 볼/스트라이크/아웃
  - 타격 결과, 수비 결과, 주자 진루
- 기록원 Lock
  - 동시 접속 충돌 방지
- 편의 기능
  - 단축키 ON/OFF
  - 경기 타이머 시작/일시정지
  - 문자 중계 입력
- 저장/종료
  - 경기 종료 처리
  - CSV 기록지 다운로드(재다운로드 지원)

### 3-5. 라이브 방송 제어

- 스코어보드 (`/scoreboard`) 및 문자중계 (`/scoreboard-text`) 상태 모니터링
- 라이브 오버레이 (`/live-overlay`) 송출 화면 점검
- 기록원 입력 데이터가 중계 화면에 실시간 반영

## 4. 문제 해결

### 로그인/권한 문제가 있을 때

1. 로그아웃 후 재로그인
2. 관리자 계정 여부 확인 (`/account`)
3. 관리자 기능 미노출 시 권한(`admin claim`, `roles`) 재확인

### 중계/기록 반영이 지연될 때

1. 페이지 새로고침
2. 활성 경기(match) 선택 상태 확인
3. 기록원 Lock 점유 상태 확인
