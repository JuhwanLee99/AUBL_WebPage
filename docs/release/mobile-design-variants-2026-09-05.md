# AUBL 모바일 디자인 A/B안 보존·비교 기록

## 요청과 기준

현재 웹형 디자인을 비교용 예시로 보존하고, 디자인 개편 전 앱의 형상·배치에 새 시각 디자인을 적용한 B안을 별도로 만든다. 구버전 코드를 통째로 복구하지 않고 현재의 데이터·인증·안정성 수정 위에서 화면 구조를 재구성했다.

- 이전 앱 구조 기준: `a32b8cf`, Flutter `1.0.6+15`
- A안 보존 기준: `d3625ef`, Flutter `1.1.0+16`
- B안: `1.1.0+16`의 별도 디자인 후보. 스토어 버전이나 앱 ID는 새로 만들지 않았다.

## B안의 방향

| 영역 | A안 | B안 |
|---|---|---|
| 탐색 | 플로팅 하단 바·태블릿 레일 | 이전 앱처럼 화면 하단에 붙는 6개 고정 탭 |
| 홈 상단 | 큰 캠페인·설명·사실 블록 | 짧은 시즌 배너와 고정 앱바, 전체 소개는 배너 탭으로 열기 |
| 홈 중심 | 웹 섹션을 순서대로 길게 배치 | 홈팀 공지·라이브·오늘/내일/가까운 경기·최근 결과를 먼저 배치 |
| 경기 | 큰 소개·검색 패널·목록 패널 | 월 이동·검색·상태 필터 직후 날짜별 경기 행 |
| 기록 | 큰 개요와 TOP 5 카드 강조 | 시즌·조 선택과 기록 행 우선, TOP 5는 필요할 때 펼치기 |
| 팀·커뮤니티 | 히어로와 설명 뒤에 목록 | 검색·조 선택·게시판·목록으로 바로 진입 |
| 더보기·온보딩 | 큰 안내 카드·홍보형 소개 | 계정·설정 목록, 로그인·둘러보기 동작 우선 |

### 유지한 새 디자인

- Pretendard·Barlow Condensed, 화이트·네이비·코발트, 라이트·다크 의미 색상
- 기존 투명 AUBL 로고. 홈 앱바와 온보딩은 다크 모드에서 밝은 틴트를 적용한다.
- 선명한 표면 경계와 낮은 카드 단차, 상태 목적의 색상
- 축약 캠페인에도 `우리의 청춘은 이번에도 / PLAY BALL`, 별·궤적 모티프 적용
- 작은 폰·가로 화면·글자 200%에서 늘어나는 행, 44dp 이상 터치 영역과 키보드 동작

### 홈

- 헤더만 고정하고 짧은 캠페인 배너는 스크롤되어 사라진다.
- 긴 시즌 설명과 사실 블록은 삭제하지 않고 배너 탭의 소개 시트에서 확인한다. 소개 시트의 경기·순위 버튼은 시트를 닫고 기존 목적지로 이동한다.
- 최신성은 간단한 정보줄로 표시한다. 저장본·갱신 필요·미확인 상태를 구분하고 펼치면 기존 게시 revision·출처·시각을 확인한다.
- 팀 공지를 위쪽에 두며 최근 2개와 팀 페이지 진입을 제공한다.
- 공식 예정 경기에서 오늘·내일을 구분하고 둘 다 없으면 가까운 예정 경기를 보여준다. 홈은 미리보기이며 전체 경기는 경기 탭에서 확인한다.
- 목록·달력 선택 저장, 선택 날짜의 일정, 조별 현황, 시즌 리더, 리그 공지와 파트너를 유지한다.
- 조별 상태는 서버 판정을 사용한다. 경기 카드의 간단한 팀·점수 행과 별도로 조별 표에서 으뜸·버금·동률 상태를 확인한다.
- 파트너는 반복적인 큰 카드 대신 간결한 링크 목록으로 정리했다. 골드볼파크(공인구), 메이저(배트), UniquePlay, Instagram을 유지한다.

### 경기·기록

- 경기의 현재 4탭과 필터·달력·조별 순위·라이브·연습경기는 유지한다. 구버전의 데이터 원천으로 돌아가지 않는다.
- 공식 경기는 KST 날짜별로 묶고 날짜 미정 경기도 제거하지 않는다. 같은 날짜에는 시각·백엔드 ID 순으로 안정적으로 표시한다.
- 경기 상태·점수 쌍·조·진출 상태·구장과 상세 동작을 조밀한 경기 카드로 표시한다. 글자가 큰 경우 세로 배열로 전환한다.
- 기록의 기본 모바일 필터는 시즌·조에 즉시 접근한다. 추가 필터와 명시적인 검색 적용은 기존 동작을 유지한다.
- 작은 기록 행에 선수·팀·주요 기록을 함께 표시하고, 넓은 화면의 전체 기록표도 유지한다.
- 선수 상세는 현재 선택된 선수의 정보를 먼저 표시하고 다른 선수 검색은 펼쳐서 사용한다.

## 변경하지 않은 기능·데이터 계약

- Spring/MariaDB 공식 시즌 API와 Firestore 라이브·콘텐츠 분리
- 활성 revision만 공개, 기존 수동 기록 보존, sourceActive/deleted 필터, null 기록 처리
- KST 기준 날짜, 캐시 revision, 요청 경합 방지
- Firebase/Google/Apple 로그인, 사용자·팀 권한, 댓글·답글 저장
- 공지 접기·revision별 24시간 숨김, 테마 선택 저장
- 알림 초기화 첫 프레임 분리, 토픽 직렬화, OFF·로그아웃 정합성
- 관리자·UniquePlay·기록원·경기 편집·전광판의 웹 경로·인증
- 관리자가 직접 버튼을 눌렀을 때만 UniquePlay를 수집하는 정책
