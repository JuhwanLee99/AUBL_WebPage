# AUBL 모바일 테스트 안내 (1.0.2+11)

문서 일자: 2026-03-01  
대상 빌드: `1.0.2+11` (`app-release.aab`)

## 1) 테스트 목적

- 기록원 권한 계정의 메뉴 노출/진입 동작이 의도대로 동작하는지 검증
- 관리자 권한과 기록원 권한의 기능 경계(노출/접근)가 정확히 유지되는지 확인
- 계정 화면 역할 표기가 권한 데이터(`roles`)와 일치하는지 확인

## 2) 사전 준비

1. 테스트 빌드 설치
- 내부 테스트 트랙에서 `1.0.2 (11)` 설치

2. 계정 준비
- 일반 계정 1개
- 기록원 계정 1개 (`roles/{uid}.role = scorer`)
- 관리자 계정 1개 (`admin claim = true`)

3. 확인 환경
- Android 1대, iOS 1대 (권장)

## 3) 필수 테스트 시나리오

1. 기록원 메뉴 노출 확인
- 경로: `더보기`
- 절차:
  1. 기록원 계정 로그인
  2. 더보기 진입
- 기대 결과:
  - `기록원` 섹션이 표시됨
  - `기록원`, `경기 기록 수정` 메뉴가 표시됨
  - `관리자 패널`, `일정 관리`, `스코어보드`는 표시되지 않음

2. 관리자 메뉴 노출 확인
- 경로: `더보기`
- 절차:
  1. 관리자 계정 로그인
  2. 더보기 진입
- 기대 결과:
  - `관리자` 섹션이 표시됨
  - `기록원`, `경기 기록 수정`, `관리자 패널`, `일정 관리`, `스코어보드` 메뉴가 표시됨

3. 일반 계정 메뉴 비노출 확인
- 경로: `더보기`
- 절차:
  1. 일반 계정 로그인(또는 비로그인)
  2. 더보기 진입
- 기대 결과:
  - 관리자/기록원 운영 메뉴가 표시되지 않음

4. 기록원 페이지 진입 확인
- 경로: `더보기 > 기록원`
- 절차:
  1. 기록원 계정에서 진입
  2. 웹 기록원 페이지가 정상 로드되는지 확인
- 기대 결과:
  - WebView가 정상 로드되고 기록원 화면 접근 가능

5. 경기 기록 수정 진입 확인
- 경로: `더보기 > 경기 기록 수정`
- 절차:
  1. 기록원/관리자 계정에서 각각 진입
  2. `/admin/games` 목록 확인 및 상세(`/admin/games/:matchId`) 진입
- 기대 결과:
  - 두 권한 모두 진입 가능
  - 목록/상세 화면 로딩 정상

6. 계정 역할 라벨 확인
- 경로: `더보기 > 계정`
- 절차:
  1. 기록원 계정 로그인 후 계정 화면 확인
  2. 관리자 계정 로그인 후 계정 화면 확인
- 기대 결과:
  - 기록원 계정: `기록원 (기록/중계)`로 표시
  - 관리자 계정: `관리자 (정식 승인)`으로 표시

## 4) 회귀 테스트(간단)

1. 인증
- 로그인/로그아웃 후 더보기 화면 상태 즉시 반영

2. 커뮤니티
- 공지 목록/상세 진입
- 댓글 등록/삭제(권한 범위 내) 동작 확인

3. WebView 공통
- WebView 진입 후 로딩 실패/무한로딩 없는지 확인
