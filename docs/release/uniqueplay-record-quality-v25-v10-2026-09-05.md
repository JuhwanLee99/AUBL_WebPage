# UniquePlay 상세 품질 v25 v10 배포와 전수 검수

## 결과

업로드 승인 후 백엔드 v25와 워커 v10을 Docker Hub에 올리고 NAS 컨테이너를 교체했다. 운영 데이터 수집·정정·게시·활성화는 하지 않았다. 기존 공개 리비전 `ca075759-16ef-48c6-913f-a55453bda54f`를 유지했다.

저장된 v9 실행 `f994f85b-b6dc-4845-8b47-dd62eb63f352` 전수 검사 결과는 117경기 중 상세 112, 미게시 5, 경고 46경기·80건, 검사 경고 없음 66경기다. 타점 7경기를 원본에서 추가 대조했다. 전체 117개 원본을 같은 시점에 재수집한 조사와 구분한다.

## 변경과 검증

- 상세의 산술 불일치를 경고로 분리하되 식별·형식·개인정보·부모 경기 점수·수집 누락은 계속 차단.
- 경기별 원본/유효값 표, 검수 체크섬, 명시적 경고 확인, 필드별 수동 정정, 수정 후보 복제, 원천 해결 및 충돌 알림 추가.
- 원본 JSON 불변 유지. 적용된 정정과 출처는 새 불변 리비전에 포함. 미게시 상세·누락된 게임/선수는 거짓 해결 처리하지 않음.
- 공개 웹 경기/선수와 Flutter 선수 기록에 오류 수정 중/해결 표시. 기존 품질 필드가 없는 자료에 임의 정상 판정 없음.
- 워커의 가상 스크롤은 끝 위치와 3회 안정화를 확인하고 미완료는 실패 처리.
- 백엔드 106, 워커/웹 120, Flutter 143개 테스트 통과. 웹 lint/typecheck/build 통과. 기존 번들 500kB 경고는 남음.

실제 운영에서는 상세 GET과 표 내보내기 등 읽기 전용 검수만 했다. 수치 수정·게시·활성화·복구의 운영 E2E는 아직 실행하지 않았다. 자동 수집이나 백그라운드 스케줄러는 추가하지 않았다.

## 검수 근거와 보류

- 후보 체크섬: `8a778a9fba18801455909640be6de5c789b90f76cbd8202215c0496e8aeab330`
- 유효 검수 체크섬: `348716925c2edbc4942b72b54e56bb215ebf97b1237bcff351f59a4dae399cef`
- 상세 전수 검사: 피안타 합계 34, 투수 실점 합계 11, 자책>실점 18, 타자 득점 합계 9, 타점>득점 1, 타점0 확인 6, 이닝 점수 1.
- 원본 타점 대조: `55840`, `55783`, `55558`, `55214`, `55133`, `54987`, `54897`. 원본 표시와 수집 후보 일치. 서강대 한정우·시립대 박휴준 홈런에 타점/득점0 확인.
- 419건 DELETE는 고유 선수 수 또는 실제 삭제를 뜻하지 않는다. 팀 별칭과 IN/OUT을 포함한 비교 키 문제는 아직 남아 있으며, 원인별 실수치는 미확정이다. 실제 미수집과 잘못된 신규/삭제 분류를 분리하기 전 현재 후보는 게시 보류.
- 기존 `run.validation`은 저장 당시 검증 결과다. 상세 검수 GET은 v25 기준 품질을 계산하지만 실행의 저장된 검증 상태를 자동으로 덮어쓰지 않는다. 다음 관리자 검증 시 새 규칙이 적용된다.
