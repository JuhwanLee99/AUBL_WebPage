# AUBL 모바일 테스트 안내 (1.0.6+15)

문서 일자: 2026-03-21  
대상 빌드: `1.0.6+15` (`app-release.aab`)

## 1) 테스트 목적

- 웹 등록 경기 시간과 Flutter 앱 표시 시간이 동일한지 검증
- 일정 날짜 분류(오늘/내일, 날짜별 그룹핑) 정확도 검증
- iOS/Android 버전 표기(`1.0.6 (15)`) 동기화 확인

## 2) 사전 준비

1. 테스트 빌드 설치
- Android: 내부 테스트 트랙에서 `1.0.6 (15)` 설치
- iOS: 동일 소스 버전(`1.0.6 (15)`) 빌드(TestFlight 또는 ad-hoc) 설치

2. 테스트 데이터 준비 (웹)
- 일정 관리에서 아래 샘플 경기 2건 등록
  - 경기 A: `09:00`
  - 경기 B: `12:00`

## 3) 필수 테스트 시나리오

1. 시간 표시 정합성 (09:00)
- 절차:
  1. 웹 일정에서 `09:00` 등록 경기 확인
  2. Flutter 앱 홈/일정 탭에서 동일 경기 확인
- 기대 결과:
  - 앱에서도 `09:00`으로 표시
  - `00:00`으로 보이지 않음

2. 시간 표시 정합성 (12:00)
- 절차:
  1. 웹 일정에서 `12:00` 등록 경기 확인
  2. Flutter 앱 홈/일정 탭에서 동일 경기 확인
- 기대 결과:
  - 앱에서도 `12:00`으로 표시
  - `03:00`으로 보이지 않음

3. 날짜 분류 정합성 (오늘/내일)
- 절차:
  1. 오늘 경기, 내일 경기 각각 1건 이상 등록
  2. 홈 화면 `오늘 일정`/`내일 일정` 카드 확인
- 기대 결과:
  - 각 경기가 올바른 섹션에 배치
  - 일정 탭에서도 동일 날짜 그룹으로 표시

4. 팀 상세 예정 경기 날짜 표시
- 절차:
  1. 팀 상세 화면 진입
  2. 예정 경기 목록 날짜 확인
- 기대 결과:
  - 웹 기준 날짜와 동일
  - UTC 변환 오차로 하루 밀림/당김 없음

5. iOS/Android 버전 표기 확인
- 절차:
  1. Android 번들 버전 확인 (`1.0.6 (15)`)
  2. iOS 아카이브/빌드 메타데이터 버전 확인 (`1.0.6 (15)`)
- 기대 결과:
  - 두 플랫폼 모두 동일 버전 표기

## 4) 회귀 테스트(간단)

1. 일정 화면 기본 동작
- 탭 전환(전체/라이브/결과/조별/연습경기) 정상

2. 홈 화면 안정성
- 홈 진입/새로고침/백그라운드 복귀 시 크래시 없음
