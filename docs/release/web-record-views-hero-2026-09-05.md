# 공식 경기 상세·문자중계와 홈 히어로 운영 릴리스

## 변경 목적과 범위

사용자 요청에 따라 로컬에서 검토한 공식 상세/운영 문자중계 두 가지 보기를 운영 웹에 반영한다. 동기화 공식 기록은 상세 기록을 기본으로 하고, 기록원이 직접 기록하는 진행 경기는 기존 Firestore 문자중계를 유지한다. 홈 히어로의 반복 안내를 줄이고 데이터 확인 현황을 하나로 합친다.

- 공식 상세: 박스스코어, 타자·투수 기록, 원본 타석 표기와 품질 상태. 상세/문자중계 토글은 같은 활성 공식 데이터를 사용한다.
- 운영 문자중계 컴포넌트 재사용: 전광판·현재 타석·요약·다시보기·기록표·CSV. 원천에 없는 투구수/볼카운트 등은 미제공으로 표시하며 0을 생성하지 않는다.
- 타순 재구성: 이닝 사이 연결과 같은 이닝 반복 타석을 처리한다. 도루·폭투 등은 별도 타석으로 세지 않는다. 모호한 교체·누락은 원문과 확인 안내로 남긴다.
- 기본 보기: 공식 데이터는 새로고침·새 경기·재진입마다 상세 기록. 과거 브라우저 보기 저장값은 무시한다. 같은 경기의 직접 기록 시작/이벤트가 없는 경우 진행 중이라는 일정 상태만으로 문자중계 기본값을 선택하지 않는다.
- 히어로: `연합회교 / FORMAT / VISION` 요약 카드와 지정된 `— 실시간 기록과 중계, 디지털화를 핵심 가치로 리그의 새로운 도약을 준비했습니다.` 문장을 제거한다. 학교와 함께하는 시즌이라는 앞 문장은 유지한다. 원격 콘텐츠에 이전 문장이 있어도 화면에서 제거한다.
- `데이터 확인 현황`을 기존 요약 카드 자리로 이동한다. 별도 중복 패널은 제거하되 일정/기록/원본 대조 상태, 확인·게시 시각, 리비전, 경고와 원본 링크는 보존한다. 라이트·다크, 좁은 화면에서의 가독성을 유지한다.

백엔드·워커·Flutter·인증/DB 규칙은 이번 릴리스 대상이 아니다. 재수집·정정·게시·리비전 활성화·수기 데이터 삭제는 실행하지 않는다.

## 검증

- `npm run check:ci`: lint, TypeScript, Vite build 통과. 기존 500 kB 번들 크기 경고 유지.
- `npm run test:uniqueplay`: 워커·공개 API·라우팅·품질·검수/정정 회귀 통과. 직접 기록 증거와 다른 경기 상태 차단 테스트 포함.
- `node scripts/test-official-game-views.mjs --browser`: 38개 통과(렌더링/타순 15 + 브라우저 23). 360·390·768·1280·1920px, 라이트/다크, 저장값 무시, 새로고침·경기 이동, 토글·CSV·확대 검증.
- `npm run test:home-hero`: 8개 통과. 원격 이전 문구 제거, 통합 패널 1개, 360·768·1280px 라이트/다크, 13px 이상 현황 본문과 44px 원본 링크, 로딩·실패 상태 검사.
- fixture 브라우저는 외부 연결을 차단하고 공개 UI만 마운트한다. 운영 데이터 쓰기나 UniquePlay 수집을 하지 않는다.
- 타순 대조: `up-f1e054d7678bf5467580de7d`의 고려대 1회 1~3번, 2회 4~9번/1~8번(14타석), 3회 9번부터. 원본 통계와 CSV 불변성 확인.
