# AUBL 모바일 테스트 안내 (1.0.2+10)

문서 일자: 2026-03-01  
대상 빌드: `1.0.2+10` (`app-release.aab`)

## 1) 테스트 목적

- 이번 버전의 주요 변경(댓글/인증/카테고리 필터)이 운영 환경에서 정상 동작하는지 확인
- 로그인/로그아웃 상태 반영 지연 이슈 재발 여부 확인
- Android 15 edge-to-edge 전환 이후 화면 인셋/잘림 이슈가 없는지 확인

## 2) 사전 준비

1. 테스트 빌드 설치
- 내부 테스트 트랙에서 `1.0.2 (10)` 설치

2. 계정 준비
- 일반 사용자 계정 1개
- 관리자 계정 1개(공지 작성/관리 화면 검증용)

3. 네트워크 조건
- 와이파이 1회, LTE/5G 1회 각각 테스트 권장

## 3) 필수 테스트 시나리오

1. 로그인/로그아웃 반영
- 경로: `더보기`
- 절차:
  1. 로그인 상태 확인
  2. 로그아웃 탭
  3. 더보기 화면 UI(로그인 버튼/배너)가 즉시 반영되는지 확인
- 기대 결과:
  - 로그아웃 후 더보기의 계정 관련 UI가 지연 없이 로그아웃 상태로 바뀜

2. 공지 댓글 입력 영역(비로그인)
- 경로: `커뮤니티 -> 공지 상세`
- 절차:
  1. 비로그인 상태로 공지 상세 진입
  2. 댓글 입력 영역 확인
- 기대 결과:
  - 입력 영역 형태는 유지
  - `로그인이 필요합니다.` 문구 노출

3. 공지 댓글 입력/등록(로그인)
- 경로: `커뮤니티 -> 공지 상세`
- 절차:
  1. 로그인 상태에서 댓글 작성
  2. 등록 후 목록 반영 확인
- 기대 결과:
  - 댓글이 정상 등록되고 즉시 목록에 노출

4. 공지 카테고리 필터
- 경로: `커뮤니티 -> 공지사항`
- 절차:
  1. 카테고리 탭에서 `심판/기록원 모집` 선택
  2. 해당 카테고리 공지 목록만 필터되는지 확인
- 기대 결과:
  - 필터 탭 표시 정상
  - 선택 카테고리 기준으로 목록 필터링 정상

5. 공지 작성 카테고리(관리자)
- 경로: `커뮤니티 -> 공지 작성`
- 절차:
  1. 카테고리 목록 확인
  2. `심판/기록원 모집`으로 공지 생성
  3. 목록/상세에서 카테고리 라벨 확인
- 기대 결과:
  - 카테고리 선택/저장/표시 정상

6. Apple/Google 로그인 동의 팝업
- 경로: 로그인 화면
- 절차:
  1. Apple 계정으로 계속하기 선택
  2. 동의 팝업 노출 확인
  3. Google 계정으로 계속하기와 동일 UX인지 확인
- 기대 결과:
  - Apple 로그인에도 동의 팝업이 동일하게 표시

7. Android 15 edge-to-edge 인셋
- 환경: Android 15+ (API 35 이상) 기기/에뮬레이터
- 경로: 랜딩, 커뮤니티, 공지 상세, 더보기, 로그인(WebView), 기록실(WebView)
- 절차:
  1. 세로/가로 회전
  2. 제스처 내비게이션 + 3버튼 내비게이션 각각 확인
  3. 상태바/하단 제스처 영역 근처 버튼 탭 동작 확인
- 기대 결과:
  - 상단 상태바/하단 시스템 영역에 텍스트 및 버튼이 겹치지 않음
  - 스크롤/탭이 정상 동작하고 잘림 또는 터치 불가 영역이 없음

## 4) 회귀 테스트(간단)

1. 커뮤니티

2. 계정

3. WebView
