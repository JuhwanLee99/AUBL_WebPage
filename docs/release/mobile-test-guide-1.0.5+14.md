# AUBL 모바일 테스트 안내 (1.0.5+14)

문서 일자: 2026-03-16  
대상 빌드: `1.0.5+14` (`app-release.aab`)

## 1) 테스트 목적

- 회칙 페이지 검색 정확도 검증
- 검색 결과 상/하 순회 및 자동 스크롤 동작 검증
- 검색 UI 변경이 기존 회칙 열람 흐름을 깨지 않는지 회귀 검증

## 2) 사전 준비

1. 테스트 빌드 설치
- Android: 내부 테스트 트랙에서 `1.0.5 (14)` 설치
- iOS: 동일 소스 버전(`1.0.5 (14)`) 빌드 설치 후 수동 확인

2. 확인 환경
- Android 1대 이상
- iOS 1대 이상

## 3) 필수 테스트 시나리오

1. 단일 키워드 검색
- 경로: `더보기 > 회칙`
- 절차:
  1. 검색창에 `몰수` 입력
- 기대 결과:
  - `몰수` 포함 항목만 노출
  - 일치 텍스트 하이라이트 표시

2. 다중 키워드 검색(AND)
- 절차:
  1. 검색창에 `몰수 벌과금` 입력
- 기대 결과:
  - 두 키워드를 모두 충족하는 항목만 노출
  - 결과 건수 표시

3. 검색 결과 순회(아래 버튼)
- 절차:
  1. 결과가 2건 이상인 검색어 입력
  2. 우측 아래 버튼 반복 탭
- 기대 결과:
  - 다음 결과로 순차 이동
  - 화면이 해당 결과 위치로 자동 스크롤
  - `현재/전체` 인덱스가 증가

4. 검색 결과 순회(위 버튼)
- 절차:
  1. 아래 버튼으로 2번째 이상 결과로 이동
  2. 우측 위 버튼 탭
- 기대 결과:
  - 이전 결과로 이동
  - `현재/전체` 인덱스가 감소

5. 순환 이동(wrap-around)
- 절차:
  1. 마지막 결과에서 아래 버튼 탭
  2. 첫 결과에서 위 버튼 탭
- 기대 결과:
  - 마지막 -> 첫 결과, 첫 -> 마지막 결과로 순환 이동

6. 검색어 초기화
- 절차:
  1. 검색창 우측 `X` 버튼 탭
- 기대 결과:
  - 검색어 삭제
  - 전체 회칙 다시 노출
  - 순회 인덱스 초기화

7. 결과 없음 케이스
- 절차:
  1. 존재하지 않는 키워드 입력
- 기대 결과:
  - `검색 결과가 없습니다` 안내 노출
  - 상/하 버튼 비활성

## 4) 회귀 테스트(간단)

1. 회칙 기본 열람
- 검색어 없이 장 펼침/접힘 정상

2. 앱 안정성
- 회칙 화면 진입/뒤로가기 시 크래시 없음
