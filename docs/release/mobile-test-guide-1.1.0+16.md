# AUBL 모바일 1.1.0+16 내부 배포 테스트 가이드

## 설치 전

- 기존 앱에서 테마와 홈 경기 보기 방식을 한 번 변경한 뒤 업데이트 설치한다.
- 관리자, 일반 사용자, 팀 소속 사용자 계정을 각각 준비한다.
- Android 24 이상 기기와 iOS 13 이상 기기를 포함한다.

## 필수 시나리오

- 첫 실행과 업데이트 실행 모두 크래시 없이 홈에 진입한다.
- 시스템/라이트/다크 선택이 앱 재시작 뒤 유지되고 WebView의 색상·시스템 바와 일치한다.
- 6개 하단 목적지와 태블릿 가로 레일에서 같은 화면으로 이동한다.
- 홈 중요공지가 보이며 접기는 세션 동안, 하루 숨김은 같은 revision에만 24시간 적용된다.
- 홈의 일정 목록/달력 선택이 저장되고 모든 경기 카드의 `경기 상세`가 `sourceGameId` 기준으로 열린다.
- 경기 화면의 일정·결과/조별/라이브/연습경기가 공식 경기와 Firestore 자료를 중복 표시하지 않는다.
- 로그인 팀의 조가 기본 선택되며 으뜸·버금·탈락·판정 대기 상태가 웹과 일치한다.
- 타자·투수 기록이 null일 때 0으로 표시되지 않고 빈/검증 중 상태가 나온다.
- 네트워크를 끊었을 때 마지막 동일 revision 저장본과 저장 시각이 표시된다.
- Google/Apple 로그인, 로그아웃, 토큰 갱신, 계정 삭제 경로를 검증한다.
- 관리자·UniquePlay·기록원·경기 편집·전광판 WebView가 기존 권한과 기능을 유지한다.
- UniquePlay는 관리자 버튼을 누르기 전에는 어떠한 수집 요청도 시작하지 않는다.
- 공지·팀 공지·경기 푸시를 눌렀을 때 `AppDestination` 기준 목적지로 이동한다.

## 접근성·레이아웃

- 360/390px 휴대폰, 768px 태블릿 세로, 1024px 이상 태블릿 가로에서 가로 스크롤이나 잘림이 없다.
- 글자 크기 100/130/200%에서 핵심 정보와 버튼을 사용할 수 있다.
- 스크린리더가 히어로 제목, 경기 상태·팀, 버튼 목적을 읽는다.
- 키보드/스위치 포커스가 논리적 순서로 이동하고 주요 터치 영역이 44dp 이상이다.
- 모션 감소 설정에서 필수 정보가 애니메이션에 의존하지 않는다.

## 중단 기준

- 로그인 또는 계정 삭제 불가
- `sourceActive=false`/`deleted=true` 경기 공개 노출
- 공식 경기와 Firestore projection 중복
- null 기록의 가짜 0 변환
- 관리자 버튼 없이 UniquePlay 수집 실행
- P0 충돌 또는 crash/ANR의 유의미한 증가

하나라도 발생하면 다음 배포 비율로 확대하지 않고 직전 스토어 버전을 유지한다.
