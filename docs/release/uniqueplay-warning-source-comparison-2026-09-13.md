# 수집 경고와 UniquePlay 원본의 대조 검토

## 결론과 검토 한계

**대조한 5경기·11개 경고에서는 수집값이 원본 화면과 달라 발생한 오류를 확인하지 못했다.** 경고 7종을 모두 포함하도록 표본을 선정했다. 이것은 49경기·83개 경고 전체가 수집 오류와 무관하다는 결론이 아니다. 나머지 44경기·72개 경고는 원본과의 개별 대조가 남아 있다.

특히 이번 후보에 추가된 경기 상세는 4건이며, 신규 4경기 중 검수 경고가 표시된 것은 57359 경기의 피안타 합계 1건이다. 이 경고는 원본에도 동일한 불일치가 있음을 확인했다. 나머지 신규 3경기의 경고가 없다는 사실은 해당 경기 모든 필드의 원본 대조를 완료했다는 뜻이 아니다.

원본과 값이 같더라도 **기록원 책임으로 단정하지 않는다.** UniquePlay의 입력 데이터, 자동 집계, 화면 표시 중 어느 단계에서 원천 불일치가 생겼는지는 이 검토만으로 판단할 수 없다.

제품 코드, DB 기록, 검수 수정안, 공식 게시·활성화는 이번 검토에서 변경하지 않았다. 테스트용 새 수집도 실행하지 않았다.

## 수집 과정에서 특별히 확인한 경계

### 투수 열 혼동 여부

실점·자책점을 서로 바꾸었을 가능성을 54987의 실제 상세 표로 확인했다. 원본 헤더 `실점` 아래에 0·0, `자책` 아래에 5·5가 직접 표시된다. 관리자 기록과 동일하므로 이 표본은 컬럼 매칭 오류가 아니다.

56553 원본의 상단 투수 요약 카드는 실점 2로 표시되지만 상세 투수 표에는 해당 투수 실점 5·자책 2가 표시된다. 수집값은 상세 표의 실점 5를 사용한다. 요약 카드만 기준으로 검수하면 수집 오류로 오판할 수 있으므로 반드시 상세 표의 헤더와 함께 대조해야 한다.

### 빈칸과 0의 구분

54987 타자 득점·타점은 원본부터 명시적인 0이다. 55140 이닝 점수는 원본부터 빈칸이며 관리자에서도 미기재로 남아 있다. 이 두 표본에서 `빈칸 -> 0` 또는 `0 -> 빈칸` 변환 오류는 확인되지 않았다.

### 선수 행 누락·중복 가능성

확인한 투수 표에서 선수별 피안타가 원본과 일치하고, 원본이 표시한 투수 합계 자체도 상대 팀 안타와 맞지 않는다. 따라서 해당 경고를 단순히 투수 행 하나를 누락한 수집 오류로 설명할 수 없다. 미대조 44경기에서는 행 누락·중복 여부를 아직 배제하지 않는다.

## 권장 후속 조치

1. 경고를 `원본과 일치하는 원천 불일치`, `원천 미기재`, `수집 불일치`, `추가 확인 필요`로 분류한다. 모든 경고에 일괄적으로 기록원 오류라는 명칭을 붙이지 않는다.
2. 미대조 44경기·72건은 같은 방식으로 원본 헤더와 선수 행을 전수 대조한 뒤 판정한다. 현재 표본 결과만으로 자동 경고 해제 또는 운영 기록 정정을 하지 않는다.
3. 수집 시점의 안전한 표 단위 근거를 원시 값·헤더·행 수·선택 팀·parser 버전과 함께 보존하는 설계를 후속 과제로 삼는다. 댓글, 연락처, 인증정보, 전체 페이지 HTML은 보존 대상에서 제외한다.
4. 이닝 전부 미기재이고 팀 득점이 0인 경우에는 `원천 이닝 미기재`와 `합계 불일치`를 구분해 설명하는 UI 개선을 검토한다. 빈칸을 자동으로 0으로 확정하는 것은 별도 정책 없이는 하지 않는다.
5. 실점·자책점·피안타를 타석이나 승패로 추정해 임의 수정하지 않는다. UniquePlay 원천 정정 또는 근거가 명시된 관리자 수정안을 사용한다.

이번 작업은 검토·문서화에 한정했다. 위 진단 분류와 근거 저장 개선은 아직 구현하지 않았다.
