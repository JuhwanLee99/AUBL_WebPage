## 1. 재현한 오류와 수정 이유

### 시작 화면과 알림

iPhone 16e / iOS 18.6 시뮬레이터에서 앱을 실행했을 때 APNs/FCM 준비·토픽 연결을 기다리는 동안 시작 로고에 머무르는 현상을 확인했다. 기존 `main`은 `runApp` 이전에 알림 초기화를 기다렸고, 홈 조회도 알림 토픽 갱신을 기다렸다.

- 첫 프레임 이후 선택적 푸시 초기화를 시작한다.
- 초기화 Future를 공유해 중복 구독 등록을 방지한다.
- 알림 탭·토큰 갱신 수신기를 네트워크 작업 전에 연결한다.
- 초기 알림의 기존 목적지 계약을 유지한다. 셸 구독 전에는 pending 1회, 구독 후에는 stream으로 전달한다.
- 홈·사용자 메뉴 렌더링은 푸시 준비와 독립적으로 진행한다.
- 토큰·사용자 ID·플랫폼 오류 원문은 로그로 출력하지 않는다.

후속 리뷰에서는 지연된 구독이 사용자의 전체 OFF·로그아웃 이후 완료되어 예전 선택을 복원할 수 있는 경합도 확인했다. 화면의 대기 시간과 실제 토픽 처리 순서를 분리하고, 최신 저장 설정을 기준으로 정합성을 맞춘다.

- native 토픽 작업은 단일 큐에서 처리한다. 10초 제한은 호출자의 대기만 끝내고 이미 시작한 작업을 동시에 다시 실행하지 않는다.
- 설정과 팀·사용자 식별값은 먼저 저장한다. 지연 작업이 끝나면 최신 설정을 읽어 다음 동작을 결정한다.
- 이전 팀·사용자의 해제 대상을 로컬에 보존하고 실제 해제에 성공한 뒤 제거한다.
- OFF와 로그아웃 회귀 테스트에서 최종 구독 해제와 native 동시 호출 최대 1개를 검증했다.

이 작업은 기존 알림 선택을 보존하기 위한 오류 수정이다. 새로운 알림 유형, 주기적 재시도 타이머나 수집 스케줄러를 추가하지 않는다.

수정 후 같은 시뮬레이터에서 시즌 히어로와 로그인·둘러보기 버튼이 있는 온보딩 화면이 정상 표시되는 것을 확인했다. 시뮬레이터의 푸시 연결 미준비는 화면 표시를 차단하지 않는다. 실제 기기에서 APNs/FCM 수신까지 성공했다고 간주하지 않는다.

### 작은 가로 화면·키보드·큰 글자

- 844×390dp, 글자 200%의 기록 화면에서 약 46dp의 하단 오버플로우를 재현했다. 높이가 짧거나 글자가 큰 경우 축약형 필터 요약과 기존 필터 시트를 사용한다.
- 768×600dp, 글자 200%, 키보드 inset 300dp에서 탐색 레일의 약 284dp 오버플로우를 재현했다. 레일 스크롤로 6개 목적지 접근을 유지한다.
- 360×640dp, 글자 200%, 키보드가 열린 표 편집 대화상자의 오버플로우를 재현했다. 본문 스크롤과 하단 동작을 분리해 내용·적용 동작에 접근할 수 있게 했다.
- 목적지나 WebView로 이동할 때 이전 화면의 입력 포커스를 해제한다.
- 테마·문의 상태 선택 시트, 도움말 역할 탭, 댓글 작성자·작성 시각·답글 동작은 큰 글자에서 스크롤·줄바꿈으로 대응한다.

### 검색과 답글

- 선수 검색 입력 변경 즉시 이전 요청을 무효화한다. 검색어를 지웠을 때 후보·오류·로딩을 바로 초기화하며, 오래된 시즌 팀 조회도 현재 상태를 덮어쓰지 못한다.
- 팀 공지 답글은 입력 상태를 초기화하기 전에 `parentId`를 보관한다. 기존 답글 저장 구조를 바꾸지 않고 원래 의도한 상위 댓글 관계를 유지한다.
- 알림 설정 시트의 커뮤니티·팀 알림 스위치는 누른 직후 시트 내부 상태를 갱신한다. 사용자 메뉴의 요약도 먼저 갱신해, 느린 이전 요청이 끝나며 최신 선택의 표시를 되돌리지 않게 한다.

## 2. 정보 표시와 조작 보정

- 경기 카드의 긴 팀명은 말줄임 대신 줄바꿈한다.
- 구장이 없거나 축약형 카드여도 상세 동작이 있으면 `경기 상세`를 표시한다.
- 날짜만 알려진 경기는 `시간 미정`을 표시한다. 날짜의 자정을 확정 경기 시각처럼 표시하지 않는다.
- 360dp 실제 중첩 패널에서 달력 각 날짜의 터치 영역이 44×44dp 이상인지 검사한다. 테두리가 내부 폭을 차감하지 않게 그려 7열의 폭을 확보한다.
- 달력 날짜와 조 선택은 단일 동작 Semantics를 제공하며, 키보드 선택을 유지한다.
- 조 이름·경기 수·팀 수와 공지 분류·제목을 큰 글자에서 세로로 배치한다.
- 출처의 내부 식별자와 `REV` 같은 표현은 `유니크플레이`, `게시 버전`으로 정리한다. revision과 저장 시각은 유지한다.
- 홈 달력과 조별 경기 조회 실패는 빈 일정으로 표시하지 않고 오류 안내·재시도를 제공한다. 홈의 최초 시즌·달력 조회 중에도 경기 없음으로 성급하게 표시하지 않는다.
