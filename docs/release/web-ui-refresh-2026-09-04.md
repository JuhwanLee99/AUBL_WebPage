# 2026 시즌 웹 UI 마무리 개편 기록

- 작업일: 2026-09-04 (KST)
- 대상 브랜치: `getResult`
- 범위: 공개 웹, 홈 콘텐츠 관리, 경기 상세 문자중계 화면
- 제외: 기록원 입력 로직, 전광판 데이터 계산, UniquePlay 수집·게시 규칙, Flutter

## 변경 목적

2026 시즌 홈에서 정립한 화이트·네이비 중심의 시각 언어를 경기, 팀, 커뮤니티와 세부 경기 화면까지 확장했다. 기존 기능과 Firestore 경로는 유지하면서 긴 목록의 초기 노출량, 모바일 탐색, 표 가독성, 다크 모드와 44px 터치 영역을 정리했다.

## 단계별 변경

### 1. 홈 중요공지와 경기 바로가기

- 커밋: `0df6605 feat(home): add managed announcement and match shortcuts`
- 관리자 랜딩 편집 화면에서 중요공지의 활성 상태, 유형, 제목, 본문과 선택 링크를 관리한다.
- 공개 홈에서 공지를 헤더와 캠페인 히어로 사이에 표시한다.
- 사용자는 공지를 현재 세션에서 접거나, 해당 공지 리비전을 24시간 숨길 수 있다.
- 다시 게시하면 새 리비전을 발급하여 이전 숨김 설정이 새 공지를 가리지 않게 한다.
- 홈의 예정 경기와 최근 결과 카드마다 `경기 상세` 버튼을 추가했다.
- 공지 데이터는 기존 `settings/liveInfo` 문서를 사용하며 이 작업만을 위한 백엔드·Firestore 규칙 배포는 필요하지 않다.
- 작업 과정에서는 실제 중요공지를 활성화하거나 게시하지 않았다.

### 2. 경기 탐색 UX 전면 개편

- 커밋: `4e774f8 feat(schedule): redesign public game browsing`
- `/schedule`, `/schedule/results`, `/schedule/groups`, `/schedule/live`, `/schedule/practice`를 공통 시즌 컴포넌트와 토큰으로 재구성했다.
- 전체 일정은 라이브·예정·종료를 각각 6경기부터 보여주고 6경기 단위로 더 보거나 접을 수 있다.
- 종료 경기는 최신 경기부터 표시한다.
- 결과는 검색, 상태, 월 필터와 날짜별 묶음, 12경기 단위 점진 노출을 제공한다.
- 조별 화면의 전체 탭은 A~H 요약만 먼저 보여주고, 개별 조와 으뜸·버금 화면은 8경기 단위로 확장한다.
- 모바일 초기 문서 높이는 실제 데이터 기준 `/schedule` 약 51,264px에서 약 4,859px, `/schedule/groups` 약 46,198px에서 약 1,416px로 줄었다.
- 데이터 분류, 권한 검사와 경기 생성·수정 payload는 변경하지 않았다.

### 3. 경기 상세 현재 타석과 기록 표

- 커밋: `281f957 style(scoreboard): refresh matchup and stats panels`
- 현재 타석을 투수·타자 두 영역으로 분리해 이름, 타순과 상황 정보를 빠르게 읽도록 재배치했다.
- 공용 타자·투수 기록 표를 시즌 네이비·중립 표면으로 통일하고 좁은 화면에서는 표 내부 가로 스크롤을 제공한다.
- 선두 열과 선수명 열을 고정해 긴 기록 표에서도 대상을 놓치지 않게 했다.
- 기록 계산, 경기 상태와 Firestore 구독 로직은 변경하지 않았다.

### 4. 팀·커뮤니티 세부 페이지 통일

- 커밋: `b488f16 style(web): unify team and community detail pages`
- 팀 디렉터리, 팀 상세·공지, 커뮤니티 허브·공지·갤러리·문의, 선수등록 게시판을 홈과 같은 카드·표·버튼 체계로 교체했다.
- 팀 로고 표면과 투명도를 라이트·다크 모드에 맞게 정리했다.
- 과도한 팀별 무지개 강조, 필 형태 장식과 고정 다크 편집기 표면을 제거했다.
- 공용 리치 텍스트 편집기에 시즌 토큰, 44px 조작부와 접근 가능한 이름을 적용했다.
- 기존 조회·작성·수정·삭제·신고·차단 권한 조건은 유지했다.

### 5. 반응형 세로 스크롤 복구

- 커밋: `2068988 fix(layout): release mobile scroll lock on resize`
- 모바일 `더보기` 시트를 연 상태에서 화면을 데스크톱 폭으로 넓히면 시트는 사라지지만 `body`의 `overflow: hidden`이 남던 결함을 수정했다.
- 900px 초과로 전환할 때 모바일 메뉴 상태를 닫아 기존 effect 정리 과정이 스크롤 잠금을 해제하게 했다.

### 6. 최종 홈 일정 전환과 시즌 화면 마감

- 커밋: `3a47cff feat(home): add monthly match calendar toggle`
- 홈 경기 목록에 목록·달력 전환을 추가해 월별 일정 탐색을 한 화면에서 제공한다.
- `5c7201a fix(home): improve calendar schedule readability`에서 달력 셀 안의 날짜·경기·상태 글자와 팀명을 한 단계 더 키우고 셀 높이를 확보했다.
- 최종 시즌 화면 마감에는 `d8d6a6e`(공용 시즌 기반), `0e13ecb`(2026 시즌 콘텐츠), `4678d50`(순위 표현), `c6e172a`(조별·수동 화면), `6fe5bd0`(시즌 운영), `3a5501c`(계정 화면), `887c3d3`(수동 검수 화면)가 포함됐다.
- 접근성 마감은 `201160a fix(a11y): close final season interface gaps`, 불완전 공개 기록 행 처리는 `be233c7 fix(records): hide incomplete published stat rows`에서 반영했다.

## 후속 결정이 필요한 기능 항목

아래 항목은 화면 디자인이 아니라 데이터 의미·권한에 영향을 주므로 이번 커밋에서 변경하지 않았다.

- 취소 경기 또는 점수 없는 경기의 결과 요약 통계 포함 여부
- 조별 분류에서 정적 팀명 추론보다 `groupCode`를 우선할지 여부
- 종료 경기의 `현재 타석`을 최종 경기 요약으로 교체할지 여부
- 수동 경기의 `postGame` 데이터 누락 가능성에 대한 저장 규칙 변경
- 비밀 문의와 댓글의 Firestore 직접 읽기 차단 및 문의 작성자의 수정 가능 필드 제한
- 공용 편집기 대화상자 버튼의 폼 제출 방지 처리

이 항목들은 운영 정책을 확정한 뒤 별도 기능 커밋과 권한 회귀 테스트로 처리한다.
