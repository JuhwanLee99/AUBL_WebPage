# AUBL 모바일 테스트 안내 (1.0.3+12)

문서 일자: 2026-03-02  
대상 빌드: `1.0.3+12` (`app-release.aab`)

## 1) 테스트 목적

- 선수 등록 게시판 권한(열람/작성)이 역할별로 정확히 적용되는지 검증
- 웹/앱 간 표 렌더링 데이터가 동일하게 표시되는지 검증
- 커뮤니티 배치 및 랜딩 배너 변경 사항이 화면별로 정상 동작하는지 검증

## 2) 사전 준비

1. 테스트 빌드 설치
- Android: 내부 테스트 트랙에서 `1.0.3 (12)` 설치
- iOS: `1.0.3 (12)` TestFlight 또는 AdHoc 빌드 설치

2. 계정 준비
- 일반 계정 1개
- 선수 계정 1개
- 기록원 계정 1개 (`roles/{uid}.role = scorer`)
- 감독 계정 1개
- 관리자 계정 1개 (`admin claim = true`)

3. 확인 환경
- Android 1대, iOS 1대, 웹 브라우저 1종 이상

## 3) 필수 테스트 시나리오

1. 선수 등록 게시판 접근 권한
- 경로: `커뮤니티 > 선수 등록 게시판`
- 절차:
  1. 일반 계정 로그인 후 진입 시도
  2. 선수/기록원 계정으로 진입 시도
- 기대 결과:
  - 일반 계정: 접근 불가 안내 표시
  - 선수/기록원: 목록 열람 가능

2. 분류별 작성 권한
- 경로: `선수 등록 게시판 > 글쓰기`
- 절차:
  1. 관리자 계정 글쓰기 진입
  2. 감독 계정 글쓰기 진입
- 기대 결과:
  - 관리자: `선수 등록`, `유니폼 등록` 모두 선택 가능
  - 감독: `유니폼 등록`만 선택 가능

3. 작성 기본 분류 확인
- 경로: `선수 등록 게시판 > 글쓰기`
- 절차:
  1. 관리자 계정으로 신규 작성 화면 진입
- 기대 결과:
  - 기본 분류가 `선수 등록`으로 선택되어 있음

4. 표 작성/렌더링 일치성 (핵심)
- 경로: `선수 등록 게시판 > 글쓰기`
- 절차:
  1. 웹에서 표를 붙여넣거나 표 에디터로 40행 이상 데이터 작성 후 저장
  2. 동일 게시글을 앱(Android/iOS)에서 열람
- 기대 결과:
  - 앱에서도 표 형태 유지
  - 웹과 앱의 행 개수/데이터 양이 동일
  - 하단 행까지 스크롤로 확인 가능

5. 앱 표 셀 편집
- 경로: `선수 등록 게시판 > 글쓰기/수정`
- 절차:
  1. 앱에서 표 삽입
  2. 셀 값 수정 후 저장
  3. 상세에서 재확인
- 기대 결과:
  - 수정한 셀 값이 저장/재표시됨

6. 웹 커뮤니티 2x2 레이아웃 고정
- 경로: `웹 커뮤니티`
- 절차:
  1. 데스크톱 브라우저 폭을 넓게/좁게 변경
- 기대 결과:
  - 항상 한 줄 2개 구성 유지
  - 영역 배치: 공지(좌상), 건의/문의(우상), 선수 등록(좌하), 갤러리(우하)

7. 랜딩 배너 링크 검증
- 경로: `웹/앱 랜딩 또는 홈 하단`
- 절차:
  1. 유니크 플레이 배너 탭
- 기대 결과:
  - 웹: 링크 정상 이동
  - 앱: 설치 시 앱 우선 이동 또는 정상 URL 이동

## 4) 회귀 테스트(간단)

1. 인증
- 로그인/로그아웃 후 권한별 UI 즉시 반영

2. 커뮤니티 공통
- 공지/건의/문의/갤러리 진입 및 상세 로드 정상

3. 리치 텍스트 공통
- 링크/이미지/동영상/표 혼합 게시글에서 렌더링 오류 없음
