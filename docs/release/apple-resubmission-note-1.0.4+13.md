# App Store 재심사 제출 문안 (1.0.4+13)

문서 일자: 2026-03-04  
대상 빌드: `1.0.4 (13)`

## 1) App Store Connect 답변 문안 (영문, 권장)

Hello App Review Team,

Thank you for your review and feedback regarding Guideline 1.2 (User-Generated Content).

We have addressed the requested safeguards in version **1.0.4 (13)**:

1. **Flagging objectionable content**  
Users can now report objectionable user-generated content from action menus on posts/comments.

2. **Blocking abusive users**  
Users can block abusive users from the same action menus.

3. **Immediate feed removal after blocking**  
When a user is blocked, that user’s posts/comments are immediately hidden from the blocker’s community feed and detail views.

4. **Developer notification on block/report**  
Both report and block actions create moderation reports in our developer moderation queue for review.

5. **Moderation SLA**  
Our moderation policy is to review reports within 24 hours and remove violating content/accounts.

### How to verify in the app

- Community > Inquiry detail > top-right action menu (`Report / Block`)  
- Community > Notice detail > comment action menu (`Report / Block`)  
- Community > Player Registration detail > top-right action menu (`Report / Block`)  
- Team Notice detail > comment action menu (`Report / Block`)  
- More > Account > Blocked Users (manage/unblock)

If needed, we can provide a test account and additional reproduction steps.

Thank you.
