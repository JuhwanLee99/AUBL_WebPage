### 심사 정보 메모 (1.0.6)

- AUBL은 아마추어 야구 리그 운영/참여를 위한 앱입니다.
- 공지/건의/문의/선수 등록 등 커뮤니티 기능을 제공합니다.
- 이번 버전 핵심 변경:
  - 웹 등록 경기 시간과 앱 표시 시간의 UTC 오차 보정
  - 일정 날짜 분류(오늘/내일/그룹핑) 로컬 기준 통일
  - iOS/Android 버전 표기 `1.0.6 (15)` 동기화 정비

1. 로그인/로그아웃 동작 확인
- Google/Apple 로그인 정상 진입 및 복귀
- 로그인 후 세션 유지, 로그아웃 후 접근 제어

2. 신고 기능 확인 (UGC)
- 건의/문의 게시글/댓글에서 신고 메뉴 노출
- 공지 댓글, 팀 공지 댓글, 선수 등록 게시글에서 신고 메뉴 노출
- 신고 제출 시 사유 선택/상세 입력 가능

3. 차단 기능 확인 (UGC)
- 댓글/게시글 메뉴에서 작성자 차단 가능
- 차단 직후 해당 사용자 콘텐츠가 즉시 숨김 처리
- 계정 화면에서 차단 목록 확인 및 차단 해제 가능

4. 운영자 조치 흐름 확인
- 신고/차단 시 서버 신고 큐(`contentReports`) 생성
- 차단 정보는 사용자별 차단 컬렉션(`userModeration`)에 저장

5. 일반 안정성 확인
- 로그인 직후 선수 등록 게시판 권한 즉시 반영
- 화면 전환/새로고침/네트워크 불안정 상황에서 오류 복구

## Google Play Console

- 짧은 설명(예시): `AUBL 공식 앱: 일정·기록·순위·커뮤니티`
- 전체 설명(1.0.6):
  AUBL은 전국대학아마추어야구연합회 운영 및 참여를 위한 공식 앱입니다.

  주요 기능
  - 커뮤니티 공지 확인
  - 팀 공지 및 팀 정보 열람
  - 건의/문의 등록 및 처리 현황 확인
  - 사용자 생성 콘텐츠 신고/차단 및 차단 관리
  - 경기/기록 관련 웹 기능 연동
  - 계정 관리(로그인/로그아웃/회원 탈퇴 안내)

  이 앱은 리그 참여자와 운영진이 필요한 정보를 빠르게 확인하고, 공지와 소통을 효율적으로 관리할 수 있도록 설계되었습니다.

  이용 안내
  - 일부 기능은 로그인 후 이용할 수 있습니다.
  - 권한 및 데이터 처리는 개인정보처리방침과 운영약관을 따릅니다.
  - 건의/문의 작성 시 파일 직접 업로드는 지원하지 않으며, 필요한 경우 외부 링크(예: Google Drive) 또는 안내된 이메일로 자료를 전달할 수 있습니다.
- 카테고리: `스포츠`
- 콘텐츠 등급: 설문 기반 산정
- 데이터 보안: `docs/release/mobile-data-disclosure-mapping.md` 기준 입력
