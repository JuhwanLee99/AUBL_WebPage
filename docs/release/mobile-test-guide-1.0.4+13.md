# AUBL 모바일 테스트 안내 (1.0.4+13)

문서 일자: 2026-03-04  
대상 빌드: `1.0.4+13` (`app-release.aab`)

## 1) 테스트 목적

- UGC 신고/차단/차단관리 동작이 정책 요구사항대로 동작하는지 검증
- 차단 즉시 숨김이 커뮤니티 목록/상세/댓글에 일관 적용되는지 검증
- 로그인 직후 선수 등록 게시판 권한이 즉시 반영되는지 검증

## 2) 사전 준비

1. 테스트 빌드 설치
- Android: 내부 테스트 트랙에서 `1.0.4 (13)` 설치
- iOS: `1.0.4 (13)` TestFlight 또는 AdHoc 빌드 설치

2. 계정 준비
- 일반 계정 1개
- 선수 계정 1개
- 기록원 계정 1개 (`roles/{uid}.role = scorer`)
- 감독 계정 1개
- 관리자 계정 1개 (`admin claim = true`)
- 신고/차단 대상 테스트 계정 1개 이상

3. 확인 환경
- Android 1대, iOS 1대, 웹 브라우저 1종 이상

## 3) 필수 테스트 시나리오

1. 게시글 신고 동작
- 경로: 공지/건의문의/선수등록 상세 우측 경광등 메뉴
- 절차:
  1. 로그인 사용자로 상세 진입
  2. `게시글 신고` 선택
  3. 신고 사유 선택 + 상세 입력 후 제출
- 기대 결과:
  - 신고 완료 스낵바 표시
  - Firestore `contentReports`에 `action=report`, `status=pending` 저장

2. 댓글 신고 동작
- 경로: 공지 댓글, 건의/문의 댓글, 팀 공지 댓글 우측 경광등 메뉴
- 절차:
  1. 댓글 메뉴에서 `댓글 신고` 선택
  2. 사유 입력 후 제출
- 기대 결과:
  - 신고 완료 스낵바 표시
  - `contentReports`에 댓글 도메인(`*Comment`)으로 신고 저장

3. 사용자 차단 동작 + 즉시 숨김
- 경로: 게시글/댓글 메뉴의 `작성자 차단`
- 절차:
  1. 대상 사용자 차단 실행
  2. 목록/상세/댓글 화면으로 즉시 복귀하여 콘텐츠 확인
- 기대 결과:
  - 차단 즉시 대상 콘텐츠 숨김
  - `userModeration/{me}/blockedUsers/{targetUid}` 문서 생성
  - `contentReports`에 `action=block` 신고 저장

4. 차단 해제 동작
- 경로: `더보기 > 계정 > 차단한 사용자`
- 절차:
  1. 차단 목록 진입
  2. `차단 해제` 실행
- 기대 결과:
  - 차단 문서 삭제
  - 이후 대상 콘텐츠 다시 노출

5. 로그인 직후 선수 등록 권한 반영
- 경로: `커뮤니티 > 선수 등록 게시판`
- 절차:
  1. 로그아웃 상태에서 앱 진입
  2. 선수/기록원 계정으로 로그인
  3. 즉시 선수 등록 게시판 배너 탭
- 기대 결과:
  - 권한 재평가 후 접근 가능
  - 권한 부족 계정은 안내 메시지 유지

6. 공지 본문 UID 미존재 케이스
- 절차:
  1. `uid` 없는 기존 공지 상세 진입
- 기대 결과:
  - `게시글 신고` 메뉴 노출
  - `작성자 차단` 메뉴는 비노출

7. 갤러리 링크
- 경로: `커뮤니티 > AUBL 갤러리 배너`
- 기대 결과:
  - `https://m.dcinside.com/board/aubl` 외부 브라우저 이동
