# 홈 오늘의 경기: 종료 결과 유지

## 변경 이유

홈의 목록 보기에서 오늘 경기를 `scheduled` 상태에서만 선택해 결과가 수집되면 해당 경기가 오늘 목록에서 사라졌다. 날짜 소속과 경기 진행 상태를 분리하여 당일 전체 일정을 계속 확인할 수 있게 한다.

## 변경 내용

- KST 기준 오늘의 공식 경기를 예정·진행·종료·취소 상태와 관계없이 시간순으로 표시한다.
- 종료 경기에는 기존 카드의 종료 상태, 점수, 경기 상세 링크를 그대로 표시한다.
- 오늘 경기가 있으면 `오늘의 경기` 제목과 목록을 우선하고, 4경기를 넘더라도 모두 표시한다.
- 종료된 오늘 경기는 `최근 경기 결과`에도 계속 표시한다. 최근 결과의 내림차순·최대 4경기 규칙은 유지한다.
- 오늘 경기가 없을 때의 진행 중 경기·가장 가까운 예정 경기 대체 표시와 달력 보기는 유지한다.
- 삭제 경기, 연습경기, 다른 시즌 제외 규칙은 변경하지 않는다.

## 영향 범위

- 공개 웹 홈의 경기 선택 및 안내 문구만 변경한다.
- 백엔드 API, DB, UniquePlay 수집·검증·게시, Flutter에는 변경이 없다.
- 수집이나 게시 작업을 실행하지 않으며 운영 데이터를 수정하지 않는다.
- 구현 커밋 `efc656d`에서는 로컬 반영과 빌드·검증만 수행했다. 이후 사용자 배포 승인에 따라 아래 운영 배포를 완료했다.

## 검증

- `npm run test:home-matches`: 13개 통과. 예정→종료 전환, 전 경기 종료, 6경기 표시, 대체 목록, KST 자정 및 미국 브라우저 시간대, 제외 규칙, 목록/달력, 360·768·1280px 라이트/다크, 상세 링크 터치 영역·포커스를 검사한다.
- `npm run test:home-hero`: 기존 8개 통과.
- `npm run typecheck`, 변경 컴포넌트 ESLint, 새 테스트 스크립트 구문 검사, `git diff --check`: 통과.
- `npm run build`: 통과. 기존 번들 크기 경고는 남아 있다.
- 브라우저 테스트는 격리된 로컬 fixture만 사용하며 외부 네트워크를 차단한다. 운영 API·Firebase·UniquePlay 및 사용자의 로그인 브라우저를 사용하지 않는다.
