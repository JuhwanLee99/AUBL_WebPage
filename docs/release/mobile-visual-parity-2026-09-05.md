# AUBL Flutter 2026 웹·앱 시각 정합성 마감 기록

- 작업일: 2026-09-05 (KST)
- 대상: `flutter_app` `1.1.0+16` 소스
- 범위: Flutter 라이트·다크 테마, 앱 셸, 공개 홈·경기·기록·팀·커뮤니티·계정·온보딩·점검·더보기·도움말·약관, 리치 텍스트 편집 표면
- 제외: 백엔드 및 Firestore 규칙, UniquePlay 수집·검증·게시 로직, 기록원·전광판·관리자 웹 기능 재구축, 스토어 제출·배포

## 1. 웹 기준과 적용 원칙

기준은 2026 웹 홈의 캠페인 히어로와 공통 시즌 컴포넌트다. 참고 스크린샷은 무드보드로만 사용했으며 앱 자산으로 삽입하지 않았다.

- 기본 색은 화이트·시즌 네이비·코발트·중립 회색으로 제한했다.
- 성공·주의·오류 색상은 상태를 전달할 때만 사용했다.
- 일반 콘텐츠 표면은 1px 경계, 4px 코너와 낮은 단차로 정리했다.
- 한글 본문·제목은 Pretendard, 캠페인 워드마크·영문 라벨·숫자는 Barlow Condensed를 사용했다.
- 네이티브 플로팅 탐색, 바텀시트, 다이얼로그와 같은 플랫폼 오버레이는 조작 맥락에 맞는 둥근 코너를 예외로 유지했다.
- 라이트·다크에서 같은 정보 계층과 상태 의미를 유지하되 표면·텍스트·구분선 대비를 각각 조정했다.

## 2. 캠페인 히어로

`SeasonCampaignHero`를 별도 컴포넌트로 추가해 웹 히어로의 정보 계층과 형상을 Flutter에 맞게 옮겼다.

- 상·하단 룰과 선형 코너, 야구공·궤적·십자형 별 모티프를 `CustomPainter`로 그렸다.
- `우리의 청춘은 이번에도` 한글 리드와 `PLAY BALL` 영문 워드마크를 분리해 한글·영문 글꼴, 이탤릭, 자간과 행간을 웹에 맞춰 보정했다.
- 시즌 설명과 연합회교 안내, `경기 일정 · 결과`/`조별 순위 보기` 동작, 연합회교·리그 구성·비전 3개 정보 블록을 포함했다.
- `호스트`, `호스트 대학`, `HOSTED BY`와 같은 이전 용어는 원격 콘텐츠에 남아 있어도 `연합회교`로 정규화하며, 내장 기본값도 `중앙대학교(서울)` 연합회교 표기를 사용한다.
- 560dp 미만, 560~819dp, 820dp 이상으로 타이포그래피·여백·아트 밀도를 변경하고, 큰 글자에서 정보 블록을 세로로 전환한다.
- 접근성 트리에서 장식 아트를 제외하고 캠페인 제목을 하나의 간결한 헤딩으로 제공한다.

이 히어로는 일반 카드를 확대한 형태가 아니라, 웹 히어로의 배치·선·타이포그래피·장식 밀도를 따로 비교해 구현한 전용 표면이다. 앱은 동일한 캠페인 언어를 유지하면서 휴대폰에서 버튼과 정보 블록을 안전하게 줄바꿈한다.

## 3. 화면별 변경 범위

### 홈

- 최대 1180dp 폭에 중앙 정렬하고 520dp을 기준으로 외부 여백을 조정했다.
- 공지, 히어로, 데이터 최신성, 일정·결과, 조별 현황, 기록 리더, 공지·커뮤니티, 파트너 순서를 유지하면서 각 영역을 `SeasonSectionPanel`로 구분했다.
- 경기 목록을 `가까운 예정 경기`와 `최근 경기 결과`로 구분하고, 아이콘만 있던 동작을 `전체 일정`, `전체 순위`, `전체 기록`, `전체 공지` 텍스트 동작으로 명확히 표시했다.
- 기존 목록·달력 전환, 공지 접기·24시간 숨기기, 경기 상세 열기 동작은 그대로 유지했다.

### 앱 셸과 탐색

- 휴대폰은 6개 목적지를 플로팅 하단 탐색으로, 768dp 이상은 플로팅 레일로 표시한다.
- 1024dp 이상에서 레일의 라벨을 확장하고, 큰 글자의 휴대폰에서는 선택한 목적지 라벨만 보여 6개 터치 대상의 가독성을 유지한다. 각 목적지의 툴팁과 의미 라벨은 유지한다.
- 가로로 짧은 휴대폰은 폭만으로 태블릿으로 판정하지 않고 하단 탐색을 유지해, 6개 목적지가 세로 레일에서 잘리는 문제를 막는다.
- 홈 앱바에는 배경이 투명한 기존 AUBL 로고 자산을 사용했다.

### 경기

- 일정·결과, 조별, 라이브, 연습경기 화면을 공통 `SeasonPageHero`, `SeasonSectionPanel`, `PublicMatchCard`로 정리했다.
- A~H조를 4열/넓은 화면 8열로 모두 노출하고 으뜸·버금 필터를 별도 행으로 분리했다.
- 월 이동 헤더는 작은 화면·큰 글자에서 `오늘로 이동` 동작을 다음 행으로 배치한다.
- 달력 날짜는 최소 44dp 터치 영역을 제공하고, 글자가 큰 경우 작은 `N경기` 문구 대신 상태 점을 사용한다. 전체 정보는 접근성 라벨과 선택 날짜 아제다에 남는다.
- 화면 전환 애니메이션은 기기의 모션 감소 설정을 따르도록 조정했다.
- 조·월 선택을 빠르게 바꾸어도 느린 이전 API 응답이 최신 선택을 덮어쓰지 않도록 요청 세대와 선택 월을 함께 확인한다.

### 기록과 선수 상세

- 개요·팀 순위·투수·타자·파워랭킹·선수 상세의 카드, 필터, 표 타이포그래피를 공통 토큰으로 맞춴다.
- 작은 화면의 리더·순위는 카드 형식으로 유지하고, 넓은 기록표는 필요한 폭을 보존한 가로 스크롤로 제공한다.
- 필터 제어는 넓은 화면에서 여러 열로 배치하고, 작은 화면·큰 글자에서 한 열로 변경하여 라벨과 선택값을 자르지 않는다.
- 검색 필드의 임시 입력과 적용된 필터를 분리해, 닫기만 한 검색 시트가 기록 목록을 바꾸지 않게 했다.
- 작은 화면은 별도 정렬을 선택하기 전까지 API의 공식 순위를 그대로 표시하고, 정렬 제어·공식 순위·순서 방향을 Semantics에 제공한다.
- 선수 상세의 제어와 선수 식별 정보는 큰 글자에서 세로로 전환하고 보조 기술에서 의미가 명확히 전달되도록 문구를 보정했다.
- 기록 값, null 필터, API 조회 조건과 선수 상세 식별 방식은 변경하지 않았다.

### 팀·커뮤니티·기타 공개 화면

- 팀 디렉터리는 최대 1180dp 안에서 반응형 격자를 사용하고, 로고를 와이드 카드 배경이 아닌 독립 패널과 세로 구분선 안에 표시한다.
- 팀 디렉터리의 요약·조 선택·결과 격자를 하나의 슬라이버 스크롤로 연결해, 작은 화면·200% 글자에서도 고정 헤더가 팀 카드를 밀어내지 않게 했다.
- 팀 상세는 로고·팀 정보를 분리하고 승·무·패를 무지개색 필 대신 숫자 정보 블록으로 표시한다.
- 커뮤니티 허브에 시즌 히어로를 추가하고, 공지·문의·선수 등록 목록·상세·작성 표면을 1px 경계·4px 코너와 네이비·코발트 중심으로 정리했다.
- 긴급·징계·처리 중·오류와 같은 의미 상태에만 주의·오류·성공 색상을 남겼다.
- 더보기의 로그인 안내와 메뉴, 사용 설명서의 히어로·아코디언·문제 해결, 개인정보 처리방침·이용약관의 문서 카드에도 같은 규칙을 적용했다.
- 계정, 온보딩, 서비스 점검 안내, 리그 소개·회칙 화면에 캠페인 히어로와 공통 섹션 패널을 적용하고, 계정 상태·역할·삭제 동작이 라이트·다크에서 같은 정보 계층을 갖게 했다.
- 공지·문의 등의 리치 텍스트 편집기, 뷰어, 표 삽입 도구는 하드코딩된 슬레이트 다크 표면 대신 현재 테마의 시즌 토큰을 사용한다. 편집 Delta·저장·콜백 계약은 그대로다.
- 공개 본문은 휴대폰 전체 폭을 사용하되 태블릿·넓은 화면에서 820~1000dp 내외의 최대 폭으로 중앙 정렬했다.

## 4. 보존한 기능과 계약

본 작업은 시각 계층·레이아웃·조작 가독성을 변경한 것이며 데이터 정책을 변경하지 않았다.

- Spring/MariaDB·Firestore 담당 범위와 공식 경기 병합 규칙
- `provider + sourceGameId`, `sourceActive`, `deleted`, `syncRevision` 처리
- UniquePlay 공식 누적 기록 우선과 null 기록 제외 규칙
- 공지 접기·리비전별 24시간 숨기기, 홈 목록·달력 선택 저장
- 팀·커뮤니티·문의·선수 등록의 조회·작성·수정·삭제·신고·차단 권한
- `AppDestination` 기반 푸시·내부 이동과 6개 메뉴 목록
- Firebase 토큰 교환, Google·Apple 로그인, 로그아웃·계정 삭제 계약
- 관리자·UniquePlay·기록원·경기 편집·전광판·라이브 오버레이 WebView 경로와 테마 브리지
- 관리자가 명시적으로 버튼을 누를 때만 UniquePlay 수집을 시작하는 수동 실행 정책

Flutter 앱은 백그라운드 UniquePlay 수집 스케줄러를 추가하지 않았다. 기록원·전광판·관리자 화면의 기능 로직도 변경하지 않았다.

사용성 보정은 화면 적응, 명시적 필터 적용, 최신 요청 보장, 모션 감소와 Semantics 개선으로 한정했다. 새 API, 쓰기 권한, WebView 경로·인증 메시지, 자동 수집 트리거는 추가하지 않았다.
