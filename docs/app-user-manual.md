# 📘 AUBL 앱 플랫폼 사용 설명서

본 문서는 AUBL 모바일 앱을 이용하는 방문자(Guest), 일반 회원(Member), 관리자 및 기록원(Admin/Scorer)을 위한 기능별 가이드입니다.

## 공통 안내

- 앱 구조: 하단 탭 `홈 · 팀 · 일정 · 기록 · 커뮤니티 · 더보기`
- 일부 관리자 기능은 앱 내 WebView로 웹 관리 화면에 연결됩니다.
- 네트워크 상황에 따라 캐시 데이터가 먼저 보이고 최신 데이터가 뒤이어 반영될 수 있습니다.

---

## 1. 👥 방문자 (Guest) 가이드

대상: 로그인하지 않은 일반 사용자  
권한: 공개 정보 열람, 일정/기록/공지 조회, 문자중계 열람

### 1-1. 메인 및 리그 정보

앱 홈/정보 화면에서 리그 핵심 정보를 확인합니다.

- 홈 탭
  - 라이브 경기, 오늘 일정, 내일 일정, 최근 결과 확인
  - 당겨서 새로고침으로 최신 데이터 반영
- 팀 탭
  - 팀명 검색
  - 조(A~H) 필터
  - 조별/이름순 정렬
  - 팀 카드 진입으로 팀 상세 확인
- 더보기 > 리그 정보
  - 리그 소개
  - 회칙
  - 개인정보 처리방침
  - 이용약관

### 1-2. 경기 일정 및 결과 확인

일정 탭에서 경기 상태를 목적별로 확인합니다.

- 전체: 전체 경기 일정 확인
- 라이브: 진행 중 경기만 조회
- 결과: 종료 경기 조회
- 조별: 조별 경기 필터 조회
- 순위: 순위 화면 진입
- 연습경기: 연습경기만 별도 조회

경기 카드를 누르면 문자중계/결과 화면으로 이동합니다.

### 1-3. 순위 및 기록실

기록 탭에서 시즌 기반 통합 기록을 조회합니다.

- 탭 구성
  - 개요
  - 팀순위
  - 투수기록
  - 타자기록
  - 파워랭킹
  - 선수상세
- 주요 기능
  - 시즌 선택
  - 검색/필터
  - 정렬 기준 변경
  - 선수 상세에서 시즌/게임 로그 조회

### 1-4. 승부 예측

- 현재 앱의 정식 메뉴에서는 비활성(준비 중) 상태입니다.
- 차기 버전에서 별도 노출 예정입니다.

### 1-5. 경기 중계 시청

- 일정/홈에서 경기 선택 시 문자중계 화면으로 이동
- 스코어보드/라이브 오버레이는 관리자/운영 기능과 연계된 WebView 화면에서 사용

## 2. 👤 일반 회원 (Member) 가이드

대상: 로그인 사용자(일반/선수/스태프/감독)  
권한: 방문자 권한 전체 + 계정/댓글/알림/소속팀 연계 기능

### 2-1. 로그인 및 계정 관리

- 첫 실행 온보딩
  - `로그인 / 회원가입`
  - `그냥 사용하기`
- 로그인 방식
  - WebView 로그인
  - 네이티브 Google 로그인
  - 네이티브 Apple 로그인(iOS)
- 로그인 후 계정 화면에서 확인 가능 항목
  - UID
  - 이메일
  - 로그인 제공자
  - 역할(일반/선수/스태프/감독/관리자)
  - 계정 생성일, 최근 로그인 시각
- 로그아웃
  - Firebase 세션 및 WebView 쿠키 정리
- 회원 탈퇴
  - 경로: `더보기 → 계정 → 회원 탈퇴`
  - 재인증 후 계정 삭제 진행
  - 외부 안내: `https://aubl.club/account-deletion`

### 2-2. 커뮤니티 이용

커뮤니티 탭에서 공지 및 건의/문의 게시판을 사용합니다.

**공지사항**

- 카테고리 필터: 전체, 긴급, 경기공지, 징계, 일반
- 제목/내용/작성자 기준 검색
- 공지 상세에서 내용 열람 및 댓글 작성/조회/삭제(본인 댓글)
- 갤러리 배너로 외부 커뮤니티 이동

**건의/문의 게시판**

- 커뮤니티 탭에서 건의/문의 게시판 배너로 진입
- 플랫폼(앱/웹), 말머리(5종), 처리상태 필터
  - 말머리: 기능 개선 / 버그 신고 / 사용 문의 / 경기·기록 오류 / 기타
  - 처리상태: 미처리 / 처리 중 / 처리 완료
- 비밀글은 목록에 표시되지만 작성자만 열람 가능
- 로그인 후 글쓰기 가능 / 본인 글 수정·삭제 / 댓글 작성·삭제

### 2-3. 팀 상세 및 팀 공지

- 팀 상세에서 확인 가능 항목
  - 팀 소개
  - 로스터
  - 팀 공지
  - 예정/최근 경기
- 팀 공지 상세
  - 댓글/답글
  - 좋아요
  - 본인 댓글 삭제 (관리자/해당 팀 감독은 관리 권한으로 댓글/답글 삭제 가능)

팀 공지사항 게시판 주요 사용 흐름

- 목록 화면(팀 상세 내 팀 공지)
  - 카테고리 필터: 전체/일반/훈련/경기/긴급
  - 공지 검색(제목/내용/작성자)
  - 고정 공지 우선 정렬
  - 공지 개수 및 검색 결과 개수 확인
- 상세 화면(팀 공지 상세)
  - 공지 본문 확인
  - 댓글/답글 작성, 좋아요
  - 본인 댓글 삭제 (관리자/해당 팀 감독은 관리 권한으로 삭제 가능)
- 권한
  - 로그인 시 댓글 작성 가능
  - 팀 운영 정책에 따라 일부 공지는 접근 제한될 수 있음

### 2-4. 알림 설정

더보기 > 알림 설정에서 아래 항목을 관리합니다.

- 전체 알림 ON/OFF
- 커뮤니티 공지 알림 ON/OFF
- 홈팀 공지 알림 ON/OFF
- 건의/문의 알림 ON/OFF
  - 내가 작성한 글의 처리 상태 변경 시 알림
  - 내가 작성한 글에 새 댓글이 달릴 시 알림 (작성자 본인 댓글 제외)
  - 로그인 상태에서만 동작
- 경기 알림 범위
  - 전체 경기
  - 소속팀 경기
  - 경기 알림 받지 않음

참고: 전체 알림을 OFF하면 긴급 공지를 포함한 모든 알림이 중단됩니다.

### 2-5. 감독(Coach) 팀 홈 관리 (3가지)

감독 권한 사용자는 팀 운영 작업을 아래 3가지 흐름으로 처리합니다.

1. 팀 브랜딩/소개 관리
   - 팀 로고(엠블럼) 변경, 팀 설명 추가/수정은 웹 팀 홈(`/teams/:teamId`)에서 수행

2. 팀 일정 운영 관리
   - 앱 팀 상세에서 예정/진행/최근 경기 결과를 확인
   - 필요 시 웹 일정 화면(`/schedule`, `/schedule/results`)으로 이동해 일정 운영을 진행

3. 선수 로스터 관리
   - 선수 로스터(추가/수정/정리)는 웹 팀 홈에서 관리
   - 등번호/포지션/투타/프로필 정보 기준으로 명단 운영

팀 공지사항 게시판 운영(감독/관리자)

- 앱 팀 상세에서 공지 작성(제목/내용/카테고리 + 상단 고정 옵션)
- 앱 팀 상세에서 공지 고정/해제, 공지 삭제 수행
- 팀 공지 상세에서 댓글/답글 삭제(본인 또는 관리자/해당 팀 감독 권한)
- 운영 공지는 팀원 공지 피드와 상세 댓글 화면에 즉시 반영

## 3. 🛡️ 관리자 및 기록원 (Admin/Scorer) 가이드

대상: 관리자 권한 계정  
권한: 일반 회원 권한 전체 + 운영/기록 관리 기능

### 3-1. 관리자 메뉴 진입

- 더보기 탭에 관리자 섹션이 노출됩니다.
- 관리자 권한이 없는 계정에는 관리자 메뉴가 보이지 않습니다.

### 3-2. 경기 일정 관리

- 더보기 > 일정 관리
- 앱 내 WebView로 `/schedule/manage` 진입
- 가능 작업
  - 일정 생성/수정
  - 상태 변경(예정/진행 중/종료/취소)
  - 연습경기 운영

### 3-3. 관리자 패널 운영

- 더보기 > 관리자 패널
- 앱 내 WebView로 `/admin` 진입
- 운영 기능
  - 랜딩 문구/티커 관리
  - 리그 소개 관리
  - 회칙 관리
  - 팀/조 편성 관리
  - 감독 권한 관리
  - 서비스 점검 모드 ON/OFF (`/admin/maintenance`) — 점검 메시지·재개일 설정, 저장 즉시 반영

### 3-4. 건의/문의 처리 상태 관리

- 건의/문의 게시판에서 글 상세 진입
- 처리 상태를 바텀시트 선택으로 즉시 변경
  - 미처리 / 처리 중 / 처리 완료
- 비밀글 포함 모든 글 열람 가능
- 모든 글·댓글 수정 및 삭제 가능

### 3-5. 전자 기록지 작성

- 더보기 > 기록원
- 앱 내 WebView 전체화면으로 `/scorekeeper` 진입
- 주요 작업
  - 경기 선택 및 라인업 입력
  - 타석/주루/수비 이벤트 기록
  - Lock 점유/해제
  - 단축키 모드
  - 문자 중계 입력
  - 경기 종료 및 CSV 저장/다운로드

### 3-6. 라이브 방송 제어

- 더보기 > 스코어보드
- 앱 내 WebView로 `/scoreboard` 진입
- 기록원 데이터가 문자중계/오버레이에 반영되는 상태 점검 가능

## 4. 문제 해결

### 로그인이 안 될 때

1. 앱 완전 종료 후 재실행
2. 로그아웃 후 재로그인
3. Google 로그인 문제 시 기기 Google 계정 상태 확인
4. iOS Apple 로그인 문제 시 Apple ID 로그인 상태 및 Face ID/Touch ID 설정 확인

### 데이터가 오래된 것 같을 때

1. 화면 당겨서 새로고침
2. 앱 재실행
3. 네트워크 상태 확인

### 관리자 메뉴가 보이지 않을 때

1. 계정 역할 재확인
2. 관리자 권한 반영 후 재로그인
3. 여전히 미노출 시 권한 매핑(`admin claim`, roles) 점검
