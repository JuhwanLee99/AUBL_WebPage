# 동일 revision의 비공개 확정본 재구성

작성일: 2026-09-08

## 이번 구현

`functions/scoring_test_readback.py`에 내부 조회 서비스를 추가했다. `SCORING_TEST_READBACK_ENABLED` 기본값은 비활성이며 공개 endpoint는 제공하지 않는다.

실행 참여자·read 권한·만료·중단·승인 내용을 확인한 뒤 같은 Firestore 트랜잭션에서 head, 해당 manifest, 필수 블록을 읽는다. 성공할 때만 완성된 결과를 반환하며 중간 블록을 스트리밍하거나 부분 projection을 반환하지 않는다.

- 경기·실행 범위, private head, revision·commit ID와 manifest 연결을 검사한다.
- manifest의 승인 해시·payload 해시·규칙 프로파일을 현재 실행 승인과 head에 대조한다.
- 각 블록의 범위·주소·길이·내용 해시를 재검증한다. 저장 시 검증했다는 이유로 재조회 검증을 생략하지 않는다.
- state·feed·events·stats별로 manifest의 상대 순서를 유지하는 바이트 블록 목록을 반환한다. 동일 내용의 중복 참조는 같은 스냅샷에서 한 번만 읽는다.
- `expected_revision`이 지정되면 정확히 일치해야 한다. 변경되었을 때 다른 revision의 일부 데이터를 대신 반환하지 않는다.

## 일관성과 오류 처리

head 변경이나 실행 중단이 트랜잭션과 충돌하면 기존 제한 재시도 정책으로 새 트랜잭션에서 권한과 데이터를 다시 확인한다. 성공 결과는 한 revision에 묶인다. 조회가 끝난 직후 새 커밋이 생겨도 이미 반환한 결과를 최신 revision이라고 소급해서 표시하지 않는다.

블록 누락·변조·승인 불일치는 오류로 반환한다. 서비스는 이전 정상본을 자동 보관하는 캐시를 제공하지 않으므로, 추후 화면 연결 시 기존 정상 화면을 유지하면서 오류·지연을 표시하는 정책을 별도로 구현해야 한다.

## 아직 제공하지 않는 기능

반환된 데이터는 검증된 바이트 묶음이다. JSON 사건·상태·중계·통계의 스키마 디코딩과 야구 규칙상의 상호 일치 검증은 아니다. 다른 버전의 데이터를 섞지 않는 저장 계층 계약과 경기 내용의 정합성은 별도다.

실제 관전자 API·구독·캐시 교체, 공식 전환 이후 원본 관리자 전용 정책, 최종 봉인, 조회 rate limit·인프라 부하 제한은 아직 연결하지 않았다. 운영 일반 경기 경로를 읽거나 공개하지 않는다.

## 검증 상태

최초 구현 이후 아래 실제 커밋 후 재구성, expected revision 불일치, 블록 누락·변조, 다른 경기 참조, 비참여자·중단 실행 거부, 동시 커밋 중 조회의 단일 revision 검증을 실행했다.

운영 접근·배포 없이 `BLOCKED_BEFORE_LOGIN_BACKEND`를 유지한다.

## 후속 검증 결과

2026-09-08: 신규 재구성 조회 8건과 기존 커밋·장애·서버 경계 52건을 함께 실행하여 **에뮬레이터 60건 통과, 실패·제외 0건**을 확인했다. 제품 코드는 변경하지 않았다. 이번 실행에서 단위 테스트는 별도로 재실행하지 않았다.

- 정상 커밋의 revision·commit ID·payload 해시와 네 종류의 바이트 묶음을 재조회했다.
- expected revision 불일치, 누락·변조·다른 경기 블록, manifest 해시 불일치를 거부했다.
- 비참여자·기능 비활성·중단 실행의 접근을 거부했다.
- 커밋과 조회를 두 스레드로 실행했다. 반환된 revision에 대응하는 commit ID·payload 해시·projection 버전이 모두 일치했으며, 이후 새 revision 지정 조회도 통과했다.

합성 바이트와 projection 버전 구분을 이용한 저장 계층 일관성 검증이다. 실제 야구 데이터, 브라우저 구독, 장애 시 이전 화면 유지, 공식 전환 이후 관리자 전용 조회의 검증으로 확대하지 않는다.

테스트 범위의 manifest·영수증·head·세션·인계·블록·예약·실행 문서를 삭제하고 부재를 재조회했다. 원본 로그·요약은 `outputs/server-consistent-readback-2026-09-08/`에 보존했다. 운영 접근·외부 네트워크·배포는 없었다.

다음 저장 계층 작업은 최종 revision·commit ID·hash를 대조하는 비공개 봉인 계약과 봉인·늦은 쓰기 경합이다. 야구 사건 의미 검증·실제 모달 writer·IDB 큐·공식 전환 통합은 별도 잔여 과제로 유지한다.
