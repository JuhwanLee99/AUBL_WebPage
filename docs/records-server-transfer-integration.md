# 실행 인가·제한 transport·불변 블록의 내부 통합

작성일: 2026-09-08

## 이번 연결 범위

`functions/scoring_test_transfer.py`에 서버 내부 서비스를 추가했다. 외부 callable·HTTP endpoint, 활성화 API, 경기 writer와는 아직 연결하지 않았다.

승인 사본의 구조·해시·승인자와 현재 실행 정보를 대조한다. 참여자, 대상 프로젝트·API, 경기 목록, 한도, 승인·만료 시각 등 승인된 필드가 바뀌면 거부한다. 실행 status의 전이와 별도 카운터 갱신만 승인 원문의 변경으로 취급하지 않는다. 감사 사본 없는 구형 내부 등록은 이 서비스에서 사용할 수 없다.

## 제한된 외부 읽기

1. 서버 인증에서 얻은 UID로 참여자·역할·실행·승인 해시를 확인한다.
2. transport의 서버 설정 origin과 실행의 승인 origin을 대조하고 경로 허용 목록을 확인한다.
3. 해당 경로·경기·승인 해시를 묶은 요청으로 호출 예산을 예약한다.
4. 연결 직전 다시 인가하고 제한 transport를 호출한다.
5. 응답을 반환하기 전에 다시 인가한다. 중단·만료·승인 변경이 확인되면 데이터를 반환하지 않는다.

중단이 연결 직후 발생한 경우 이미 진행 중인 네트워크 요청을 즉시 취소하는 기능은 아니다. 응답 후 재인가로 반환을 막으며 전송 deadline·취소 처리는 별도 endpoint 과제다. 같은 읽기의 재시도는 경로와 권한을 재검증하며 과거 외부 응답을 자동 고정하거나 공식본으로 게시하지 않는다.

## 업로드 검증과 비공개 불변 저장

1. 스트림을 읽기 전에 실행과 승인 상태를 확인한다.
2. 실제 크기·SHA-256 검증이 끝난 임시 스트림만 사용한다.
3. 검증된 실제 크기로 업로드 예산을 예약한다. 요청 해시에 경기별 block ID·크기·내용 해시·승인 해시를 포함한다.
4. Firestore 트랜잭션 안에서 현재 실행 인가, 승인, 예약 영수증 바인딩을 다시 확인한다.
5. `scoringTestRuns/{runId}/uploadBlocks/{blockId}`에 create-only 저장한다. 동일 내용 재요청은 기존 블록을 사용하고 다른 내용은 덮어쓰지 않는다.

블록은 경기 ID와 내용 해시로 주소를 구분한다. 다른 경기의 같은 내용도 별개 경로로 저장한다. 이 내부 구현의 단일 블록 상한은 128KiB이며 전체 경기를 한 문서에 넣는 방식이 아니다.

업로드 예약 이후 중단·만료가 발생하면 최종 저장을 거부한다. 예약 비용은 자동 환불하지 않는다. 원래 예약과 저장된 블록의 보존·고아 정리 정책을 후속 manifest 구현과 연결해야 한다.

## 공개·보안 제한

이 단계는 **비공개 준비 블록**만 저장한다. 경기 head, 최종 커밋 영수증, 관전자 manifest, 점수판·중계 revision을 생성하거나 갱신하지 않는다. 반환값의 `published: false`는 이를 명시한다. 선수·야구 규칙의 의미 검증이나 작성 세션·lockEpoch 검증도 아직 이 전송 서비스에 포함하지 않았다.

기존 Firestore namespace 차단으로 클라이언트 직접 읽기·쓰기는 계속 금지된다. 서버 Admin SDK 서비스이므로 외부 진입점에서 Firebase 인증·전용 운영자 프로비저닝 및 올바른 UID 전달을 보장해야 한다. 이 모듈 자체는 JWT 검증기가 아니다.

검증 전 스트림을 읽는 비용, 이미 거부된 요청의 인프라 비용, 실제 endpoint 동시성·timeout 제한은 별도로 필요하다. 모든 기존 NAS 호출이 이 서비스를 거치도록 바뀐 것은 아니다.

## 검증 상태와 다음 작업

후속 통합 검증을 실행했다. 이전 I/O 테스트 결과를 재사용한 것이 아니라 아래 전체 단위 회귀 및 에뮬레이터 검증을 다시 실행했다.

다음 검증은 승인 사본 위변조·현재 설정 변경, 읽기 전후 중단, 검증 실패 시 예약·블록 부재, 예약 후 중단, 동일 요청 재시도·블록 불변성, 경기 간 분리, 에뮬레이터 테스트 블록 삭제·재조회다. 외부 읽기는 스텁으로 검증한다.

외부 API 공개·운영 실행 등록·활성화·배포는 하지 않았다. 전체 상태는 `BLOCKED_BEFORE_LOGIN_BACKEND`다.
