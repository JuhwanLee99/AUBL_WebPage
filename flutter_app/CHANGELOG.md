# Changelog

## 1.1.0+16 — 2026-09-04

### 2026-09-05 모바일 오류·사용성 후속 점검

- iOS에서 APNs/FCM 응답이 지연되면 시작 화면에 머무를 수 있던 문제를 수정했다. 첫 화면을 먼저 표시하고 푸시 초기화를 분리했으며, 홈·사용자 메뉴도 알림 토픽 연결을 기다리지 않는다.
- 초기 알림은 앱 셸 준비 전에는 보관하고 준비 후에는 기존 탐색 스트림으로 전달한다. 중복 초기화와 알림 연결 지연에 대한 회귀 테스트를 추가했다.
- 알림 토픽 작업을 직렬화하고 최신 설정을 먼저 저장해, 늦은 구독이 알림 OFF·로그아웃 선택을 되돌리지 않게 했다. 이전 팀·사용자의 해제 대상은 성공할 때까지 로컬에 보존한다.
- 글자 200%·가로 화면의 기록 필터와 키보드가 열린 태블릿 탐색 레일에서 재현된 오버플로우를 수정했다. 탭·WebView 전환 시 이전 입력 포커스도 해제한다.
- 선수 검색을 지우거나 시즌을 바꾼 뒤 느린 이전 검색 결과가 다시 나타나던 문제를 수정했다.
- 경기 카드의 긴 팀명을 줄바꿈하고, 구장 정보가 없어도 경기 상세 동작을 표시한다. 날짜만 있는 경기의 시간을 임의의 `00:00` 대신 `시간 미정`으로 표시한다.
- 실제 360dp 홈 패널 안에서도 달력 날짜의 가로·세로 터치 영역을 최소 44dp로 유지하고, 스크린리더의 중복 날짜 안내를 제거했다.
- 홈 달력·조별 경기 조회 실패를 경기 없음과 구분하고 다시 시도 동작을 제공한다. 출처·게시 버전 안내는 사용자용 한국어로 정리했다.
- 댓글 작성자·시간·답글 동작, 도움말 탭, 표 편집 대화상자, 테마·문의 상태 시트를 큰 글자와 키보드에 맞게 줄바꿈·스크롤 처리했다.
- 알림 설정 스위치가 즉시 갱신되지 않던 표시 문제와 팀 공지 답글의 상위 댓글 ID가 입력 초기화 과정에서 사라지던 버그를 수정했다.
- 데이터 원천, 로그인·쓰기 권한, WebView 인증 계약, UniquePlay 수동 수집 정책은 유지했다. 상세 검증·후속 실기기 확인 항목은 `docs/release/mobile-ux-polish-2026-09-05.md`에 기록한다.
- 최종 전체 테스트 108개와 정적 분석을 통과했고 Android AAB·iOS no-codesign 릴리스 빌드를 다시 생성했다. 실제 iOS 시뮬레이터에서 시작 화면 개선을 확인했으며 실기기 전체 검증·스토어 업로드는 수행하지 않았다.

### 2026-09-05 시각 정합성·사용성 마감

- 웹 2026 캠페인 히어로의 선형 코너, 2px 룰, 궤적·별·야구공 모티프, 이탤릭 워드마크와 3개 시즌 정보 블록을 Flutter 전용 `SeasonCampaignHero`/`CustomPainter`로 재구성했다.
- 히어로는 참고 스크린샷을 앱에 삽입하지 않고, Pretendard와 Barlow Condensed 및 라이트·다크 토큰을 사용해 해상도와 테마에 독립적으로 렌더링한다.
- 홈 정보 구조를 중앙 1180dp 안에서 공지, 캠페인, 데이터 최신성, 가까운 예정 경기·최근 결과, 조별 현황, 기록 리더, 커뮤니티, 파트너 순으로 다시 정리했다.
- 공통 히어로·섹션·경기·상태 컴포넌트와 팀, 커뮤니티, 더보기, 도움말, 약관 화면을 1px 경계와 4px 시즌 표면으로 통일했다. 상태 의미가 없는 무지개색·글로우·장식성 필 표현은 제거했다.
- 계정, 온보딩, 점검 안내, 리그·회칙 소개와 공지·문의·선수 등록 상세·작성기까지 같은 정보 계층과 반응형 표면을 적용했다.
- 공지·문의 등에서 사용하는 리치 텍스트 편집기·뷰어·표 삽입 UI를 테마 토큰, 44dp 조작 영역, 4px 표면으로 재정리했다. Delta 데이터와 저장 콜백은 변경하지 않았다.
- 팀 카드는 로고를 독립된 정사각형 패널과 구분선 안에 배치하고, 라이트·다크 표면에서 엠블럼과 팀명의 대비를 보정했다.
- 경기 화면에 큰 글자에서 적응하는 월 이동, A~H조·으뜸·버금 전체 선택, 44dp 날짜 터치 영역과 선택 날짜 일정 표시를 적용했다.
- 기록 화면은 필터 요약과 리더 카드, 순위·선수 상세, 넓은 기록표의 가로 탐색을 반응형 폭과 큰 글자에 맞게 보정했다.
- 검색어는 명시적인 검색 동작에서만 적용하고, 작은 화면의 초기 순서는 API의 공식 순위를 그대로 유지하도록 보정했다. 정렬 방향·공식 순위는 스크린리더에도 명확히 전달한다.
- 팀 디렉터리를 하나의 스크롤 흐름으로 바꾸고, 조 선택과 요약이 큰 글자에서도 카드 목록을 가리지 않게 했다.
- 조·월 필터를 연속으로 바꿀 때 느린 이전 응답이 최신 선택을 덮어쓰지 않도록 요청 세대를 검사하고, 애니메이션 감소 설정과 작은 가로 화면의 하단 탐색을 보정했다.
- 360·390dp 휴대폰, 768·1024dp 태블릿, 100·130·200% 글자 크기를 대상으로 히어로, 6개 탐색 목적지, 경기 제어, 기록, 팀 카드, 온보딩·점검, 약관의 widget·golden 회귀 범위를 보강했다.
- 데이터 원천·API, 라운트, 로그인·권한, 공지·문의 작성, 관리자·기록원 WebView와 UniquePlay 수동 실행 규칙은 변경하지 않았다.
- 변경 코드로 Android AAB와 iOS no-codesign 릴리스 빌드를 다시 생성했다. 실기기 검증과 스토어 제출·배포는 아직 진행하지 않았다.

### 디자인과 탐색

- 웹의 2026 화이트·네이비·코발트 토큰을 Material 3 라이트·다크 테마로 이식했다.
- `시스템·라이트·다크` 테마 선택과 영구 저장을 추가했다.
- `홈·팀·경기·기록·커뮤니티·더보기` 6개 목적지를 휴대폰 플로팅 바와 태블릿 가로형 플로팅 레일로 구성했다.
- Pretendard, Barlow Condensed와 배경 없는 AUBL 로고를 번들링했다.
- 공개·사용자 화면의 기존 다색 칩, 글로우, 과도한 그라데이션을 공통 카드·표·상태 배지로 교체했다.

### 시즌 정보와 경기

- 홈에 관리자 중요공지, 2026 캠페인 히어로, 데이터 최신성, 일정·결과 목록/달력, A~H 조별 현황, 기록 리더, 공지·파트너를 연결했다.
- 히어로 표기는 `46TH AUBL · 2026 연합회교 중앙대학교(서울)`로 통일했다.
- UniquePlay, 골드볼파크(공인구), 메이저(배트), Instagram 링크를 추가했다.
- 경기 탭을 `일정·결과 / 조별 / 라이브 / 연습경기`로 정리하고 모든 공식 경기 카드에서 상세 화면을 열 수 있게 했다.
- 홈과 일정 달력은 셀 안에 팀명을 축소하지 않고 경기 수·상태와 선택 날짜의 14sp 이상 일정 목록을 분리했다.

### 데이터 정확성과 오프라인

- Spring/MariaDB의 `/api/seasons`, `/overview`, `/api/games`를 공식 2026 시즌 원천으로 사용한다.
- 공식 UniquePlay 경기와 Firestore projection을 합산하지 않고, Firestore는 라이브 상태와 연습경기를 담당한다.
- `sourceActive=false` 또는 `deleted=true` 경기는 저장 상태를 유지하면서 공개 화면에서 제외한다.
- `provider + sourceGameId`, `groupCode`, `syncRevision`, 진출 상태를 앱 모델에 보존한다.
- null 기록을 0으로 만들지 않으며 필수 기록이 전부 비어 있는 랭킹 행은 제외한다.
- 공식 API 캐시를 시즌·조회 범위·게시 revision별로 분리하고 같은 revision만 오프라인 복구한다.
- API 시각과 날짜 경계를 기기 시간대와 무관하게 KST로 정규화한다.

### WebView와 운영

- 관리자, UniquePlay, 기록원, 경기 편집, 전광판·라이브 오버레이는 검증된 웹 구현을 유지한다.
- 네이티브 테마를 최초 URL과 `aubl-native-theme` 이벤트로 WebView에 전달한다.
- Firebase 토큰 교환과 Google·Apple 로그인 메시지 계약은 변경하지 않았다.
- UniquePlay 수집 스케줄러나 백그라운드 자동 실행은 추가하지 않았다. 관리자의 명시적인 웹 버튼 동작만 허용한다.
- FCM/APNs 토큰과 Apple nonce 원문 로그를 제거했다.

### 출시 기반

- Flutter 3.41.6, Dart 3.11.4, Java 17, iOS 13, Android minSdk 24를 고정했다.
- 공개 환경별 `dart-define` 프로필에 `AUBL_BACKEND_API_URL=https://api.aubl.club`을 명시했다.
- Android/iOS 버전 원천을 `pubspec.yaml`의 `1.1.0+16`으로 통일했다.
- Flutter 3.41.6의 iOS UIScene lifecycle과 implicit engine 플러그인 등록 방식을 적용했다.
